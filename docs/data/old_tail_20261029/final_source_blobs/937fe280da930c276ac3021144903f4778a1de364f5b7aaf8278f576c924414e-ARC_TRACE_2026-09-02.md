## 1. 剰余の代数と弧

`a(n) = k·n + r`（`0 ≤ r < n`）と書く。加算・減算のどちらのステップも `r → r − k` である
（`a(n) ± (n+1) = (k ± 1)(n+1) + (r − k)`）。従って弧（Chaffin: `r` が増加するまでの区間）の内部で
`r` は単調非増加で、弧の底（最小値）は弧の**最後の遅延着地**（`k = 0` の時刻）に一致する
（10^10 までの全 39 弧で検証）。`k` は ping-pong の「段」で、`k = 1/2` が interior/exterior の
交互（本リポジトリの chain）、`k = 3/4` はその一段上である。

検証：先頭 19 個の弧の底は Chaffin の A393814/A393815 と一致。[10^9, 10^10) の 10^7 未満の底
4 件（2426 @ 1610186343、2405 @ 2789149734、89386 @ 4910724199、110522 @ 8416516444）も添字まで一致。

## 3. 遅延着地の直後（6 弧の trace 内の遅延着地 10,405 件）

- `v−1` が穴である ⟺ 2 歩後に `v−1` へ遅延着地する（comb の継続）：10,405 件中 10,405 件。
  comb（`v, v−1, v−2, …` を 2 時刻ごとに）は 213 本、長さは 1 が 139 本、2 が 29 本、
  4〜2411 が 45 本。
- comb の末端（`v−1` 既訪問、213 件）では必ず、+1 で `c+v+1`、+2 で `2c+v+3`、+3 の候補
  `c+v` は軌道自身の直前の値 `a(c−1)` なので塞がれ、`3c+v+6`（`k = 3`）へ跳ね上がる
  （`late_landing_popup` の通り、213/213）。
- その後 +4 の候補 `2c+v+2` が未訪問なら軌道は `k = 2` へ戻り、+5 の候補 `c+v−3` が未訪問なら
  高さ `v−8` の `k = 1` へ戻って降下が続く（`AAABB…`、213 件中 45 件）。`c+v−3` が既訪問なら
  `k = 2/3` の ping-pong（`AAABABAB`）に入り、`k = 2` の候補 `c+v−2−3i` が空くと `k = 1` へ戻る。
- **+4 の候補 `2c+v+2` が既訪問なら `k = 3/4` の ping-pong に固定される**：下側 `3c+v+5−i`
  （降順、未訪問）、上側 `4c+v+11+i`（昇順）、剰余は 1 対ごとに 7 減る。`k = 3 → 2` の候補
  `2c+v−1−3i` は、`i ≤ T−2` では comb の先行する歯の test 値 `2c_t+v_t+2`、`i ≥ T−1` では弧自身の
  `k = 2` 上側 run（`a(c−2−2j) = 2c+v−1−j`）の値なので、run の長さ `J` の範囲では塞がれる。
- **訂正（`E-037`、`arc_death_rule_probe`、10^10）：固定は run を越えた最初の候補が未訪問なら破れる。**
  blocked な comb 末端 19,386 件のうち break 15,926、固定のまま剰余が尽きる（wrap）8、`k=3` 値が
  既訪問で `k=5` へ上がる 3,452。break の添字は `i_gen = (T−1) + ⌊(J_eff+2)/3⌋`
  （`J_eff = J + [run 開始が減算]`）で 12,777/15,926 件が一致し、残りは先行する歯の test 値が
  未訪問（`i ≤ T−2`、2,551 件）か run の先にも既訪問値が続く場合である。固定が弧を終わらせるのは
  剰余が先に尽きるときだけで、その条件は **`v < 13 + 7·i_pred`**（`k=4` 時刻の剰余 `v−6−7i ≥ 4`、
  `k=3` 時刻の剰余 `v−10−7i ≥ 3` から）：観測 wrap 8 件のうち 7 件が予測どおり、break 15,926 件は
  全て予測どおり、例外 1 件（`c=101762018`、`v=25231`、`i_pred=2644` だが run の先も既訪問で
  `i=3603` まで固定が続いた）。この節の旧版の「遅延着地は二度と起きない」は誤りだった。

## 4. 深い弧の終端は 6 本とも同一の局所事象

6 本すべてで、底 `v` は comb の末端（`v−1` 既訪問）であり、+3 で `k = 3` へ跳ね、**+4 の候補
`2c+v+2` も既訪問**で `k = 3/4` に固定され、その後 689〜63,910 歩で剰余が尽きた。
底の値の mod 3：4202→2、14804→2、2426→2、2405→2、89386→1、110522→2。

訂正（`E-037`）：6 本のうち固定のまま剰余が尽きた（wrap）のは弧 35・36・37 の 3 本で、いずれも
`v < 13+7·i_pred`（14804 < 13+7·2243、2426 < 13+7·1342、2405 < 13+7·3702）を満たす。弧 30・38・39 では
固定は `i = i_gen`（463、5,702、3,663）で破れて `k=2/3`・`k=1/2` 段の降下が再開したが、掃いた帯に穴が

## 5. 位置エネルギーとしての読み替え（`E-036` で範囲を限定）

`k = 1` の時刻 `m`（高さ `h`）の直後の `k = 2` 上側値は `2m + h + 1` なので、`Φ(m) = 2m + h`
と置くと、弧の `k = 2` 上側 run は `Φ + 1` の並びである。純粋な `k = 1/2` 段では高さが 2 時刻に 3
減り `Φ` は 2 時刻に 1 増える。`k = 2/3` 段では `Φ` が下がる（`level23_exit`、K 対で `K−1`）。
comb 末端 `(c, v)` の test 値 `2c+v+2` は `Φ(c−1) + 3` なので、**同じ弧の run が塞ぐ場合には**
「既訪問 ⟹ `Φ` が走行最大値から 3 以上下がっている」が成り立つ。しかし逆は成り立たず、
`arc_potential_probe`（10^10、落差の定義された comb 末端 44,421 件、`E-036`）では blocked かつ
落差 < 3 が 318 件（test 値は前の弧が `k=4` 値として訪問していた）、fresh かつ落差 ≥ 3 が 2,745 件
あり、**落差 3 は固定の必要条件でも十分条件でもない**。39 弧のうち「底 = 最初の落差 ≥ 3 の comb
末端」は 0 本、「底 = 最初の blocked comb 末端」も 0 本である。`Φ` の減少は `k ≥ 3` を経由する区間で
のみ起こり（45,859 件、`maxk ≤ 2` は 0 件）、`maxk = 3` では `size = gap/2 − 2` が 21,316/21,316 で
成り立つ。旧版のこの節の同値主張は撤回する。

## 6. landing floor への含意（`E-036`/`E-037` で訂正）

- 弧の底は弧の最後の遅延着地であり、10^10 までの comb 末端を持つ 36 弧すべてで底は comb 末端である
  （blocked 21、fresh 15）。弧が終わる（底以後に遅延着地がない）経路は 3 つ：(a) blocked で
  `v < 13+7·i_pred` により固定のまま剰余が尽きる（8 件）、(b) blocked で固定が破れた後、または fresh で
  `k=2/3` 段から `k=1` へ戻った後、帯を掃いても穴がなく剰余が尽きる（break 後 11 件、fresh 後 15 件、
  うち fresh の 2 件は `c+4` 以前、2 件は `k=2/3` 段の中で尽きる）、(c) `k=3` 値が既訪問で `k=5` へ
  上がった後に同様に尽きる（2 件）。つまり **`Φ` の落差ではなく、剰余 `v` の残量と、再開した降下が
  穴を見つけるか**が弧の終わりを決める。
- 852655 が着地されるには、ある弧が 852655 の剰余類で高さ 852656 に達する必要があり、そのためには
  直前の comb 末端 `(c, v)`（`v > 852655`）からの降下が (a)(b)(c) を回避して 852656 まで届かなければ
  ならない。(a) は `v ≥ 13+7·i_gen` なら回避される。(b) では `k=1/2` 段が消費する帯 `(c, c+v)` の
  未訪問 run と、掃いた先に自クラスの穴があるかが問題になる。
- 次の課題は、break 添字 `i_gen` と wrap 条件 `v < 13+7·i` の Lean 化（剰余の算術）と、Chaffin の
  穴集合の上で (b) の exact な費用（run 長 `J` と歯数 `T` から次の穴までの距離）を持つ hole-hopping
  ゲームの到達可能性を 852655 に対して計算することである。`H-20260902-05` の受入条件 3 をこの形に
  更新した。
