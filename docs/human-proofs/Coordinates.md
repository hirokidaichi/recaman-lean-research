# Coordinates

**役割:** 三角数、商・剰余表現 `QuotRem`、符号付きポテンシャル `G(q,r) = r − U(q)` という軌道解析の座標系を定義する。

## このモジュールの役割

本研究の中心的な視点は、正の時刻 `n` における軌道値を `a n = n·q + r` (r < n) と書き、商 `q` と剰余 `r` を座標として力学を追跡することである。本モジュールはその座標系の純粋に算術的な部分を用意する: 除算を使わない三角数の再帰定義、商・剰余の証明付き表現 `QuotRem`、そして有限降下の尺度となる符号付きポテンシャル (potential: 座標 `(q,r)` に対する符号付き整数 `G(q,r) = r − upperTri q`) である。さらに、符号付き `G` に関する等式・不等式を自然数の剰余条件へ翻訳する同値定理群を一箇所に集約し、後続モジュールが `Int` と `Nat` の変換で煩わされないようにしている。

## 主要な定義

### `lowerTri` (L6)

下三角数 T(q) = q(q−1)/2。除算に伴う余分な証明を避けるため、`lowerTri 0 = 0`、`lowerTri (q+1) = lowerTri q + q` という再帰で定義する。

### `upperTri` (L11)

上三角数 U(q) = q(q+1)/2。同様に `upperTri 0 = 0`、`upperTri (q+1) = upperTri q + q + 1` と再帰で定義する。U(q) は「q 歩ぶんの歩幅の総和」であり、軌道値の自然な上界 (`OrbitBounds`) や `G` の基準線として現れる。

### `potential` (L25)

座標 `(q,r)` の符号付きポテンシャル

```text
G(q,r) = r − U(q)   (符号付き整数)
```

剰余が三角数の基準線からどれだけ上または下にあるかを測る。局所遷移で `G` が保存・増加・減少する量を追跡し、有限降下の尺度にする。

### `QuotRem` (L79)

`QuotRem n a q r` は、等式 `a = n·q + r` と厳密な剰余条件 `r < n` を証明として持つ構造体である。剰余条件があるため `(q,r)` は `a` と `n` から一意に定まり、「証明付きの商・剰余表現」として機能する。

## 定理と証明

### `upperTri_eq_lowerTri_add` (L16)

**主張:** `U(q) = T(q) + q`。

**証明:** `q` に関する帰納法。両再帰式の差が各段でちょうど 1 ずつ蓄積することを追えばよい。

### `potential_eq_ofNat_iff` (L31)

**主張:** 非負レベル `m` について `G(q,r) = m ↔ r = U(q) + m`。

**証明:** `G` の定義 `r − U(q) = m` を整数上で移項し、両辺が自然数のキャストであることから `Int.ofNat` の単射性で自然数の等式に落とす。逆向きは代入と計算である。符号付き座標から自然数算術への橋渡しをこの一箇所に集約している。

### `potential_nonnegative_iff` (L49)

**主張:** `0 ≤ G(q,r) ↔ U(q) ≤ r`。

**証明:** 整数の不等式 `U(q) ≤ r` (キャスト後) との同値変形であり、`Int.ofNat` が順序を保存・反映することから従う。非負ポテンシャル領域 (undershoot 帯など) の定義を剰余の言葉で扱えるようにする。

### `ofNat_le_potential_iff` (L63)

**主張:** `m ≤ G(q,r) ↔ U(q) + m ≤ r`。

**証明:** 前定理と同様のキャスト操作である。目標レベル `m` 以上のポテンシャルを持つことが、剰余の下界条件と同値になる。

### `preEscape_quotRem` (L94)

**主張:** `m + 9 < s` のとき、値 `2s + m + 6` は時刻 `s − 1` において座標 `q = 2`, `r = m + 8` を持つ: `QuotRem (s−1) (2s+m+6) 2 (m+8)`。

**証明:** 等式 `(s−1)·2 + (m+8) = 2s + m + 6` は展開すれば恒等式であり、剰余条件 `m + 8 < s − 1` は仮定 `m + 9 < s` そのものである。ここで「pre-escape (脱出前)」とは、現在の局所配置から強制加算を経て解析可能な別の配置へ移る escape (脱出) の直前状態を指す。

### `preEscape_potential` (L99)

**主張:** その座標のポテンシャルは `G(2, m+8) = m + 5`。

**証明:** `U(2) = 3` なので `(m+8) − 3 = m+5`。計算のみ。

### `postAddition_quotRem` (L105)

**主張:** 強制加算後の値 `3s + m + 6` は時刻 `s` において座標 `q = 3`, `r = m + 6` を持つ。

**証明:** `s·3 + (m+6) = 3s + m + 6` は恒等式であり、剰余条件 `m + 6 < s` は `m + 9 < s` から従う。

### `postAddition_potential` (L110)

**主張:** `G(3, m+6) = m`。すなわちこの強制加算はポテンシャルを `m + 5` からちょうど目標レベル `m` へ下げる。

**証明:** `U(3) = 6` なので `(m+6) − 6 = m`。pre-escape 状態からの一回の強制加算が目標面 (target surface: `G = m` を満たす座標の集合) にちょうど着地することを示す、脱出機構の算術的核心である。

### 補助補題

`lowerTri_two` (L83)、`upperTri_two` (L86)、`upperTri_three` (L89) は `T(2)=1`, `U(2)=3`, `U(3)=6` という小さな値の `decide` による計算で、`simp` 補題として登録されている。

## 全体の中での位置づけ

証明地図のモジュール層「基礎」に属し、読む順序としては `Basic` の次に当たる。`CoordinateDynamics` は本モジュールの `QuotRem` と `potential` を実軌道 (`CoordinatesAt`) に接続し、`MultiBorrow` は法の変化を `QuotRem` の言葉で処理する。`potential_*_iff` 系列は目標面・undershoot 帯・負領域など、`G` の符号や水準で領域を切るすべてのモジュールで使われる。`preEscape_*` / `postAddition_*` は脱出機構 (`Mechanisms`, `LandingSurfaces`) が用いる特定配置の算術を先取りして検証したものである。
