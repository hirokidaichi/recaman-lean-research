## 1. 剰余の代数と弧

`a(n) = k·n + r`（`0 ≤ r < n`）と書く。加算・減算のどちらのステップも `r → r − k` である
（`a(n) ± (n+1) = (k ± 1)(n+1) + (r − k)`）。従って弧（Chaffin: `r` が増加するまでの区間）の内部で
`r` は単調非増加で、弧の底（最小値）は弧の**最後の遅延着地**（`k = 0` の時刻）に一致する
（10^10 までの全 39 弧で検証）。`k` は ping-pong の「段」で、`k = 1/2` が interior/exterior の
交互（本リポジトリの chain）、`k = 3/4` はその一段上である。

検証：先頭 19 個の弧の底は Chaffin の A393814/A393815 と一致。[10^9, 10^10) の 10^7 未満の底
4 件（2426 @ 1610186343、2405 @ 2789149734、89386 @ 4910724199、110522 @ 8416516444）も添字まで一致。

## 3. 遅延着地の直後（6 弧の trace 内の遅延着地 10,405 件）

- `v−1` が穴である ⟺ 2 歩後に `v−1` へ遅延着地する（comb の継続）：10,405 件中 10,405 件。
  comb（`v, v−1, v−2, …` を 2 時刻ごとに）は 213 本、長さは 1 が 139 本、2 が 29 本、
  4〜2411 が 45 本。
- comb の末端（`v−1` 既訪問、213 件）では必ず、+1 で `c+v+1`、+2 で `2c+v+3`、+3 の候補
  `c+v` は軌道自身の直前の値 `a(c−1)` なので塞がれ、`3c+v+6`（`k = 3`）へ跳ね上がる
  （`late_landing_popup` の通り、213/213）。
- その後 +4 の候補 `2c+v+2` が未訪問なら軌道は `k = 2` へ戻り、+5 の候補 `c+v−3` が未訪問なら
  高さ `v−8` の `k = 1` へ戻って降下が続く（`AAABB…`、213 件中 45 件）。`c+v−3` が既訪問なら
  `k = 2/3` の ping-pong（`AAABABAB`）に入り、`k = 2` の候補 `c+v−2−3i` が空くと `k = 1` へ戻る。
- **+4 の候補 `2c+v+2` が既訪問なら `k = 3/4` の ping-pong に固定される**：下側 `3c+v+5−i`
  （降順、未訪問）、上側 `4c+v+11+i`（昇順）、剰余は 1 対ごとに 7 減る。`k = 3 → 2` の候補
  `2c+v−1−3i` は弧自身の `k = 2` 上側 run（`a(c−2−2j) = 2c+v−1−j`）の値なので全て塞がれ、
  剰余が尽きて弧が終わるまで遅延着地は二度と起きない。

## 4. 深い弧の終端は 6 本とも同一の局所事象

6 本すべてで、底 `v` は comb の末端（`v−1` 既訪問）であり、+3 で `k = 3` へ跳ね、**+4 の候補
`2c+v+2` も既訪問**で `k = 3/4` に固定され、その後 689〜63,910 歩で剰余が尽きた。
底の値の mod 3：4202→2、14804→2、2426→2、2405→2、89386→1、110522→2。

## 5. 位置エネルギーとしての読み替え

`k = 1` の時刻 `m`（高さ `h`）の直後の `k = 2` 上側値は `2m + h + 1` なので、`Φ(m) = 2m + h`
と置くと、弧の `k = 2` 上側 run は `Φ + 1` の並びである。純粋な `k = 1/2` 段では高さが 2 時刻に 3
減り `Φ` は 2 時刻に 1 増える。`k = 2/3` 段では高さの実効的な減りが 2 時刻に 5 で `Φ` は減る。
comb の末端 `(c, v)` で固定が起きる条件「`2c+v+2` が既訪問」は、この弧の `k = 2` run が過去に
`Φ(c) + 2` 以上まで達していたこと、すなわち **`Φ` が走行最大値から 3 以上下がった状態で comb の
末端に達したこと**と（run の連続性のもとで）同値である。弧の降下と終端は、この位置エネルギー
`Φ = 時刻 + 値`（`k = 1` 時刻では `2·時刻 + 高さ`）の走行最大値との差で記述できる。

## 6. landing floor への含意

- 弧の底は弧の最後の遅延着地であり、弧は「comb 末端で `2c+v+2` が塞がれた」瞬間に終わる。
  従って **弧の底の値 = その弧で最初に `Φ` が走行最大値から 3 以上下がった comb 末端の高さ**である。
- 852655 が着地されるには、ある弧が 852655 の剰余類で高さ 852656 に達し、かつ **それ以前の
  comb 末端の全てで `2c+v+2` が未訪問**（`Φ` が走行最大値の 2 以内に留まっている）必要がある。
- 次の課題は、`Φ` の走行最大値からの落差がどの高さで初めて 3 に達するかの法則である。落差は
  `k = 2/3` 段（comb 末端で `c+v−3` が既訪問のとき）で生じるので、帯 `(c, c+v)` の既訪問値の
  分布が鍵になる。これは `H-20260902-05` の受入条件 3 の exact 版である。
