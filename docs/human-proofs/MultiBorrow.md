# MultiBorrow

**役割:** 任意回数の借りを許した法変更の算術モデル `BorrowData` を定義し、その存在・一意性・領域分類と、全域的な座標遷移則を確立する。

## このモジュールの役割

`CoordinateDynamics` は借り (borrow: 法が `n` から `n+1` へ変わる際に商から剰余へ `n+1` を繰り入れる算術操作) が 0 回・1 回の場合だけを扱った。しかし算術的には、商 `q` が剰余 `r` より大幅に大きい配置では複数回の借りが必要になり得る。本モジュールは借り回数 `b` と補正後剰余 `s` を証明付きで保持する `BorrowData` を導入し、(1) すべての座標に借りデータが存在し一意であること、(2) `b = 0`、`b = 1`、`b ≥ 2` がそれぞれ通常領域・一段借り領域・遠方領域 (far chamber) と正確に対応すること、(3) 任意の `b` に対する加算・減算の座標遷移とポテンシャル変化の閉じた式、を証明する。これにより座標遷移は場合分けなしの全域式 (`coordinates_add_total` / `coordinates_sub_total`) になる。実軌道上では `b ≤ 1` しか起きないこと自体は `OrbitBounds` で示す。

## 主要な定義

### `BorrowData` (L9)

`BorrowData n q r b s` は、法を `n` から `n+1` へ変えるときの借り証明書であり、二条件

```text
b·(n+1) + r = q + s     (収支等式)
s < n + 1               (剰余条件)
```

を持つ。意味: 値 `n·q + r` を法 `n+1` で書き直すと `(n+1)·(q−b) + s` になる。収支等式は `s = b·(n+1) + r − q` を自然数のまま表現したもので、剰余条件が `s` を正規の新剰余にする。

## 定理と証明

### `BorrowData.zero_of_le` (L14)

**主張:** `r < n` かつ `q ≤ r` (通常領域) なら `BorrowData n q r 0 (r−q)`。

**証明:** 収支等式は `r = q + (r−q)`、剰余条件は `r − q ≤ r < n < n+1`。

### `BorrowData.one_of_chamber` (L22)

**主張:** `r < q ≤ n+1+r` (一段借り領域) なら `BorrowData n q r 1 (n+1+r−q)`。

**証明:** 収支等式は `(n+1) + r = q + (n+1+r−q)`、剰余条件は `r < q` から従う。

### `BorrowData.remainder_eq_of_eq_zero` (L31) / `BorrowData.remainder_eq_of_eq_one` (L40)

**主張:** 借り 0 回の補正後剰余は `r − q`、1 回のそれは `n+1+r−q` である。

**証明:** 収支等式に `b = 0` または `b = 1` を代入して整理するだけである。`CoordinateDynamics` の二領域の式と一致することを確認する。

### `exists_borrowData` (L51)

**主張:** `r < n` なら借りデータは常に存在する: `∃ b s, BorrowData n q r b s`。

**証明:** `q ≤ r` なら `zero_of_le` で済む。`r < q` の場合は、不足分 `q − r` を `n+1` で割る天井除算 (ceiling division) を行う。割り切れるなら `b = (q−r)/(n+1)`, `s = 0`、割り切れないなら `b = ⌊(q−r)/(n+1)⌋ + 1`, `s = (n+1) − (q−r) mod (n+1)` と取れば、除算の基本等式から収支等式が成り立ち、剰余条件も満たす。除算はこの存在証明の内部にのみ現れ、遷移則自体には露出しない。

### `BorrowData.unique` (L75)

**主張:** 借りデータは一意である: 同じ `(n, q, r)` の二つの借りデータ `(b, s)`, `(c, t)` について `b = c` かつ `s = t`。

**証明:** 仮に `b < c` とすると、二つの収支等式の差から `(c−b)·(n+1) = t − s` となるが、左辺は `n+1` 以上、右辺は `t < n+1` より `n+1` 未満で矛盾する。対称性より `b = c` が従い、そのとき収支等式から `s = t`。

### `BorrowData.eq_zero_iff` (L99)

**主張:** `r < n` のとき `b = 0 ↔ q ≤ r`。

**証明:** 左から右は収支等式 `r = q + s` から `q ≤ r`。右から左は `zero_of_le` の標準データと一意性による。

### `BorrowData.eq_one_iff` (L113)

**主張:** `b = 1 ↔ r < q ∧ q ≤ n+1+r`。

**証明:** `b = 1` なら収支等式 `n+1+r = q+s` と `s < n+1` から `r < q` と `q ≤ n+1+r` が読み取れる。逆は `one_of_chamber` と一意性である。

### `BorrowData.two_le_iff` (L129)

**主張:** `2 ≤ b ↔ n+1+r < q`。すなわち複数回の借りは遠方領域 `q > n+1+r` と正確に対応する。

**証明:** `2 ≤ b` なら収支等式から `q = b(n+1) + r − s > 2(n+1) + r − (n+1) = n+1+r`。逆に `q > n+1+r` のとき、`b = 0` は `r = q + s ≥ q` を、`b = 1` は `n+1+r = q + s ≥ q` をそれぞれ強いて矛盾するので `b ≥ 2`。

### `BorrowData.le_q_add_one` (L151)

**主張:** 借り回数は加算後の商に収まる: `b ≤ q + 1`。

**証明:** 仮に `b ≥ q+2` なら `b(n+1) ≥ (q+2)(n+1) > q + (n+1) > q + s` となり収支等式に反する (途中で `q ≤ q(n+1)` を使う)。加算遷移の商 `q+1−b` が自然数として意味を持つための上界である。

### `BorrowData.add_one_le_q_of_positive` (L169)

**主張:** さらに元の値が `n+1 < value` (減算が数値的に可能) なら `b + 1 ≤ q`。

**証明:** 仮に `q ≤ b` とすると `q(n+1) ≤ b(n+1)` と収支等式から `n·q + r ≤ s < n+1` が導かれ、`value = n·q + r ≤ n` となって `n+1 < value` に矛盾する。減算遷移の商 `q−1−b` の well-definedness を保証する。

### `quotRem_add_borrowData` (L188)

**主張:** `QuotRem n value q r`、`BorrowData n q r b s`、`b ≤ q+1` のもとで `QuotRem (n+1) (value+(n+1)) (q+1−b) s`。

**証明:** 恒等式 `n·q + r + (n+1) = (n+1)(q+1) − (q − r) = (n+1)(q+1−b) + s` を、収支等式を使って自然数のまま確認する。剰余条件は `BorrowData` のものをそのまま引き継ぐ。

### `quotRem_sub_borrowData` (L217)

**主張:** 同じ仮定と `b+1 ≤ q`、`n+1 < value` のもとで `QuotRem (n+1) (value−(n+1)) (q−1−b) s`。

**証明:** 商を `q = (q−1−b) + b + 1` と分解し、`(n+1)` の倍数の項を収支等式で置き換えると等式が閉じる。借り 0 回・1 回の場合はそれぞれ `CoordinateDynamics` の四遷移に特殊化される。

### `potential_borrowData` (L243)

**主張:** 任意の借り補正について、行き先の商 `q'` が何であれ

```text
G(q', s) = G(q, r) + b·(n+1) − q + U(q) − U(q')
```

**証明:** 収支等式を整数へキャストし、`s = b(n+1) + r − q` を `G(q', s) = s − U(q')` に代入して並べ替える。行き先の商に依存する部分を `U(q')` の項に分離した「全域ポテンシャル漂移式」であり、加算 (`q' = q+1−b`)・減算 (`q' = q−1−b`) 双方に適用できる。

### `potential_two_quotient_gap` (L266)

**主張:** 剰余を固定して商を 2 下げるとポテンシャルは奇数 `2p+3` だけ上がる: `G(p, s) = G(p+2, s) + (2p+3)`。

**証明:** `U(p+2) − U(p) = (p+1) + (p+2) = 2p+3`。

### `potential_borrow_branch_gap` (L276)

**主張:** 同一の借りデータのもとで、減算先 `(q−1−b, s)` と加算先 `(q+1−b, s)` のポテンシャル差はちょうど `2(q−1−b) + 3` である。

**証明:** 両者の商は 2 違いなので前定理をそのまま適用する。通常領域の分岐間ギャップ `2q+1` と一段借り領域のギャップ `2q−1` を同時に一般化する式である。

### `coordinates_add_borrowData` (L285) / `coordinates_sub_borrowData` (L302)

**主張:** 実軌道版。`CoordinatesAt n q r`、借りデータ、商の側の上下界、および実際の分岐 (`CanSubtract` の成否) のもとで、新しい `CoordinatesAt (n+1)` と `potential_borrowData` 型のポテンシャル式が同時に成り立つ。

**証明:** `recurrence` により `a(n+1)` を明示し、`quotRem_add_borrowData` / `quotRem_sub_borrowData` を適用する。ポテンシャル式は座標のみの補題である。

### `coordinates_add_total` (L321) / `coordinates_sub_total` (L338)

**主張:** 座標遷移の全域性。実軌道の座標点で強制加算 (または合法減算) が起きたなら、借りデータ `(b, s)` が存在して、新座標とポテンシャル式を伴う遷移が必ず成り立つ。

**証明:** `r < n` (座標の剰余条件) から `exists_borrowData` で借りデータを取り、加算側は `le_q_add_one`、減算側は `add_one_le_q_of_positive` (減算の合法性が `n+1 < a n` を与える) で商の側の条件を確認して前定理に接続する。この二定理により、実軌道の一歩はどんな配置でも座標の言葉で追跡できる。

### `coordinates_add_multi` (L358) / `coordinates_sub_multi` (L373)

**主張:** 遠方領域 `n+1+r < q` で実際に加算 (または合法減算) が起きたなら、その遷移の借り回数は必ず `b ≥ 2` である。

**証明:** 全域遷移で得た借りデータに `two_le_iff` を適用するだけである。かつて未処理だった多段借りの隙間を、算術モデルの側から閉じる定理である (実軌道側からの排除は `OrbitBounds`)。

## 全体の中での位置づけ

証明地図のモジュール層「局所遷移」に属し、状況一覧「座標力学」の借用遷移の全域式を担う。直接の後続は `OrbitBounds` で、そこで実軌道の商上界 `q ≤ n` から遠方領域が空であること、したがって実軌道の借りは常に 0 回か 1 回であることが示され、状況一覧の「多段借り (解消済み)」が完成する。`coordinates_*_total` の全域遷移とポテンシャル漂移式は、`LandingSurfaces` 以降の目標面解析や回復解析が任意配置の一歩を記述する際の共通インターフェースである。
