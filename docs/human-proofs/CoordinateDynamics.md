# CoordinateDynamics

**役割:** 実軌道の商・剰余座標 `CoordinatesAt` を定義し、通常領域と一段借り領域での加算・減算がポテンシャル `G` をどう動かすかを定量的に確立する。

## このモジュールの役割

`Coordinates` で用意した座標系を実際のレカマン軌道に載せる。時刻が `n` から `n+1` へ進むと法そのものが変わるため、座標の更新は単純な加減算にならない。本モジュールは、更新を追加の借り (borrow: 法の変化に伴い商から剰余へ `n+1` を繰り入れる算術操作) なしで書ける通常領域 (regular chamber: `q ≤ r`) と、一回の借りで書ける一段借り領域 (`r < q ≤ n+1+r`) に分け、それぞれの加算・減算について (1) 純粋な算術遷移、(2) ポテンシャルの変化量、(3) 実軌道への適用、を証明する。得られる基本語彙は「通常減算は `G` を保存する」「通常加算は `G` を `2q+1` 下げる」「一段借り減算は `G` を `n+q` 上げる」「一段借り加算は `G` を `n+1−q` だけ変える」の四つである。

## 主要な定義

### `CoordinatesAt` (L6)

`CoordinatesAt n q r` は、実軌道値 `a n` が `QuotRem n (a n) q r`、すなわち `a n = n·q + r` かつ `r < n` を満たすことを表す。実軌道の座標がこの形で取れることが、以降の全解析の前提になる。

## 定理と証明

### `exists_coordinatesAt` (L10)

**主張:** `0 < n` なら座標は必ず存在する: `∃ q r, CoordinatesAt n q r`。

**証明:** `q = a n / n`、`r = a n % n` と取れば、除算の基本等式 `a n = n·(a n / n) + a n % n` と `a n % n < n` がそのまま条件になる。

### `upperTri_pred` (L17) / `upperTri_pred_pred` (L25)

**主張:** `0 < q` なら `U(q) = U(q−1) + q`。`2 ≤ q` なら `U(q) = U(q−2) + (q−1) + q`。

**証明:** 上三角数の再帰式を一段・二段展開するだけの補助補題である。商が 1 または 2 減る遷移でのポテンシャル計算に使う。

### `potential_sub_regular` (L37)

**主張:** 通常領域 `q ≤ r` (かつ `0 < q`) での減算に対応する座標更新 `(q, r) → (q−1, r−q)` は `G` を保存する: `G(q−1, r−q) = G(q, r)`。

**証明:** `U(q) = U(q−1) + q` より `(r−q) − U(q−1) = r − U(q)`。分子・分母がともに `q` だけずれて相殺する。

### `potential_add_regular` (L44)

**主張:** 通常領域での加算に対応する更新 `(q, r) → (q+1, r−q)` は `G` を `2q+1` 下げる: `G(q+1, r−q) = G(q, r) − (2q+1)`。

**証明:** `U(q+1) = U(q) + q + 1` を代入すると差はちょうど `q + (q+1) = 2q+1` になる。加算が「重い」操作であることを定量化する式である。

### `potential_sub_borrow` (L52)

**主張:** 一段借り領域 `r < q ≤ n+1+r` (かつ `2 ≤ q`) での減算に対応する更新 `(q, r) → (q−2, n+1+r−q)` は `G` を `n+q` 上げる。

**証明:** `U(q) = U(q−2) + (q−1) + q` を代入し整理すると、新ポテンシャルは `G(q,r) + (n+1) + (2q−1) − q = G(q,r) + n + q` になる。借りにより剰余へ `n+1` が繰り込まれるぶんだけ `G` が急上昇する。

### `potential_add_borrow` (L61)

**主張:** 一段借り領域での加算に対応する更新 `(q, r) → (q, n+1+r−q)` は `G` を `n+1−q` (符号付き) だけ変える。

**証明:** 商が変わらないので `U(q)` はそのままであり、剰余の変化 `(n+1) − q` がそのまま `G` の変化になる。

### `quotRem_add_regular` (L69) / `quotRem_sub_regular` (L80)

**主張:** `QuotRem n value q r` と `q ≤ r` のもとで、値に `n+1` を加えると `QuotRem (n+1) (value+(n+1)) (q+1) (r−q)`、`n+1 < value` かつ `0 < q` のとき値から `n+1` を引くと `QuotRem (n+1) (value−(n+1)) (q−1) (r−q)` が成り立つ。

**証明:** 恒等式 `n·q + r ± (n+1) = (n+1)(q±1) + (r−q)` の確認である。新剰余 `r − q` は `r < n` から `r − q < n + 1` を満たす。減算側では `value > n+1` が引き算の well-definedness を保証する。法が `n` から `n+1` に変わるため、商の増減に伴い剰余から `q` が差し引かれる点がレカマン座標力学の特徴である。

### `quotRem_add_borrow` (L95) / `quotRem_sub_borrow` (L107)

**主張:** `r < q ≤ n+1+r` のもとで、加算は `QuotRem (n+1) (value+(n+1)) q (n+1+r−q)`、減算 (`2 ≤ q`, `n+1 < value`) は `QuotRem (n+1) (value−(n+1)) (q−2) (n+1+r−q)` を与える。

**証明:** `r < q` では `r − q` が自然数として作れないため、法一つぶん `n+1` を商から借りて剰余に繰り入れる。恒等式は `n·q + r + (n+1) = (n+1)·q + (n+1+r−q)` および `n·q + r − (n+1) = (n+1)(q−2) + (n+1+r−q)` であり、上界 `q ≤ n+1+r` が新剰余の非負性を、`r < q` が `n+1+r−q < n+1` を保証する。

### `a_succ_of_not_canSubtract` (L124)

**主張:** 減算できないとき `a(n+1) = a(n) + (n+1)`。

**証明:** `recurrence` の否定分岐の展開である。

### `a_add_then_sub_eq_pred` (L131)

**主張:** 強制加算の直後に合法減算が続くと、二歩の正味は −1 である: `a(n+2) + 1 = a(n)`。

**証明:** `a(n+1) = a(n) + (n+1)`、`a(n+2) = a(n+1) − (n+2)` を合成すると `a(n+2) = a(n) − 1`。減算の合法性から `n+2 < a(n+1)` なので引き算は自然数の範囲で正しい。

### `a_sub_then_add_eq_succ` (L145)

**主張:** 逆に、合法減算の直後に強制加算が続くと二歩の正味は +1 である: `a(n+2) = a(n) + 1`。

**証明:** 同様の合成である。この二つの「±1 補題」は、隣接値を系統的に生成する局所機構として下降・被覆解析で繰り返し使われる。

### `a_pos_of_pos_time` (L159)

**主張:** `0 < n` なら `0 < a n`。

**証明:** 最後の一歩で場合分けする。合法減算なら定義により結果は `n` より大きい正の値であり、加算なら正の歩幅 `n` が加わる。

### `coordinates_sub_regular` (L173) / `coordinates_add_regular` (L187)

**主張:** 実軌道版の通常遷移。`CoordinatesAt n q r`、通常領域条件、および実際の分岐 (`CanSubtract` の成立/不成立) のもとで、`CoordinatesAt (n+1)` の新座標と、上の `potential_sub_regular` / `potential_add_regular` のポテンシャル式が同時に成り立つ。

**証明:** `recurrence` で `a(n+1)` を明示し、対応する純算術遷移 `quotRem_*_regular` を適用し、ポテンシャル式は座標のみに依存する補題をそのまま添える。

### `coordinates_sub_borrow` (L201) / `coordinates_add_borrow` (L217)

**主張:** 実軌道版の一段借り遷移。同様に新座標 `(q−2, n+1+r−q)` または `(q, n+1+r−q)` への `CoordinatesAt` と、対応するポテンシャル変化式を与える。

**証明:** 通常版と同じ構成で、`quotRem_*_borrow` を用いる。

## 全体の中での位置づけ

証明地図のモジュール層「局所遷移」の中心であり、状況一覧の「座標力学 (証明済み)」に対応する。`MultiBorrow` は本モジュールの二領域 (借り 0 回・1 回) を任意の借り回数 `b` に一般化し、`OrbitBounds` は実軌道では `b = 0, 1` しか起きないことを示して再びこの二領域に帰着させる。四つのポテンシャル変化則は、負領域からの回復 (`Recovery` 系)、undershoot 帯の有限降下 (`Undershoot`)、目標面解析 (`LandingSurfaces`) など、`G` を尺度として使うすべての議論の計算基盤である。`InitialRegion` も本モジュールの `exists_coordinatesAt` と強制加算補題を直接使う。
