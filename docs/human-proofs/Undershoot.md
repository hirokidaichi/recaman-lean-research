# Undershoot

**役割:** 非負帯を有限化する: 非負ポテンシャル状態は商予算内で低商へ降り、`G` を厳密に下げるか被覆を返す。これにより undershoot 帯 `0 ≤ G < m` の三分岐と負・非負一周期の解析が完成する。

## このモジュールの役割

`NegativeEpoch.lean` は負エポックの出口が undershoot 帯(目標 `m` に対して `0 ≤ G < m` を満たす非負ポテンシャル帯)への着地か `CoverageStep` かであることを示した。本モジュールはその undershoot 帯側を解析する。非負ポテンシャルでは座標が通常領域 `q ≤ r` にあり、合法減算は `G` を保存して商を 1 ずつ下げるので、商に関する帰納法で「低商 `k ≤ 1` に同じレベルで到達するか、途中の強制加算が被覆を返すか」が従う。低商では 2 歩以内に `G` が厳密に下がるため、非負エポック(非負ポテンシャルから低商またはポテンシャル低下まで追う有限区間)全体でポテンシャルの厳密降下が得られる。ポテンシャルレベルに関する強帰納法でこれを繰り返すと、undershoot 帯は「被覆・負領域への復帰・同帯のより低いレベル」の三分岐に落ち、最終的に負→undershoot→負の一周期(cycle)が「親の被覆」または「値が減らない再訪(parent growth)」へ縮約される。この最後の残余が、ポテンシャル降下と値帰納の間に残る大域証明の争点である。

## 定理と証明

### `coordinates_add_regular_gives_coverageStep_below_nextTime` (L9)

**主張:** 非負通常領域(`2 ≤ q`, `q ≤ r`)での強制加算は、すべての目標 `m ≤ n + 1` に対し `CoverageStep m (a n) n` を与える。

**証明:** 減算候補 `y = a n − (n+1)` は `a n = n·q + r ≥ 2n + r` から `y ≥ n + 1` を満たし(`r ≥ q ≥ 2`)、`y < a n`。強制加算の仮定から `y` は既出であり、その初出時刻とともに `CoverageStep` の値下降枝が成立する。`NegativeEpoch.lean` の L8 と同じ blocker 論法の非負版である。

### `nonnegative_epoch_lowQuotient_or_coverage_with_value` (L44)

**主張:** `m ≤ n + 1`、`CoordinatesAt n q r`、`0 ≤ G(q,r)` のとき、時刻 `t`(`n ≤ t ≤ n + q`)と座標 `(k, s)` が存在して、`a t ≤ a n`(`t > n` なら厳密に小さい)、`G(k,s) = G(q,r)`(ポテンシャル保存)、かつ `k ≤ 1` または `CoverageStep m (a n) n`。さらに `t = n` なら `k = q`。

**証明:** 商 `q` に関する強帰納法。`q ≤ 1` なら `t = n` で直ちに終了。`q ≥ 2` のとき、非負性から `U(q) ≤ r`、よって `q ≤ U(q) ≤ r` で通常領域にいる。

- **合法減算**: 通常減算は座標を `(q−1, r−q)` に移し `G` を保存する。帰納法の仮定を次状態に適用し、値は減算で厳密に下がるので、再帰が返す被覆は `mono_parent` で親へ持ち上げ、値の追跡も維持される。歩数は商が 1 減るごとに 1 歩なので合計 `q` 以内。
- **強制加算**: L9 が被覆を返して終了。

### `nonnegative_epoch_lowQuotient_or_coverage` (L107)

**主張:** 値追跡を落とした射影: 商予算 `q` 歩以内に、同じポテンシャルレベルの低商 `k ≤ 1` 状態か被覆に達する。

**証明:** L44 から成分を取り出す。

### `coordinates_zeroQuotient_next` (L125)

**主張:** 商 0 の実座標では次の一歩は必ず強制加算で、座標は `(1, r)` に移り、`G` はちょうど 1 下がる。

**証明:** `a n = 0·n + r = r < n` なので `n + 1 < a n` が成り立たず減算は不能。通常加算の座標遷移で `(n+1, 1, r)` に移り、`G(1, r) = r − 1 = G(0, r) − 1`。

### `lowQuotient_nonnegative_potential_drop` (L148)

**主張:** 低商 `q ≤ 1` の非負状態からは、2 歩以内に `G` が厳密に下がる(下げ幅はちょうど 1 か 3)。さらに値は厳密に増え、到達値は `a n + (n+1)` か `a n + 1` のいずれかである。

**証明:** 場合分け。

- `q = 0`: L125 により 1 歩で `G` が 1 下がる。値は `a n + (n+1)`。
- `q = 1`、強制加算: 通常加算で `(2, r−1)` に移り、`G` は `2q + 1 = 3` 下がる。値は `a n + (n+1)`。
- `q = 1`、合法減算: まず `(0, r−1)` へ移り `G` は保存、続く時刻は商 0 なので L125 の強制加算で `G` が 1 下がる。2 歩の合計で `G` はちょうど 1 下がり、値は `a (n+2) = a n − (n+1) + (n+2) = a n + 1`。

いずれの枝でも 2 歩以内に厳密降下が起こる。非負帯では低商が「`G` を下げる出口」であり、L44 の商降下と合わせて非負エポック全体の降下が得られる。

### `lowQuotient_level_seen_next` (L212)

**主張:** 低商 `q ≤ 1` でレベル `G = g` にいるなら、値 `g` 自体が遅くとも時刻 `n + 1` までに履歴に現れる。

**証明:** `q = 0` なら `a n = r = g` で現在値そのもの。`q = 1` なら `r = 1 + g` で、減算候補は `a n − (n+1) = n + r − n − 1 = g`。合法減算なら `a (n+1) = g` が実際に出現する。強制加算なら候補 `g` は既出のはずである。ただし強制の理由が「値が正でない」可能性を排除する必要があり、`g = 0` は `a 0 = 0` により常に既出、`g > 0` なら `a n = n + 1 + g > n + 1` なので強制の理由は既出性しかない。

この定理は、undershoot 帯の各レベル値 `g` が探索中に必ず履歴へ記録されることを示し、履歴予算(`missingBelowCount`)を使う下流の議論への接続点になる。

### `nonnegative_epoch_records_level_or_coverage` (L266)

**主張:** レベル `G = g` の非負状態からは、被覆が得られるか、`n + q + 1` までに `g` が履歴に現れる。

**証明:** L107 で低商へ降り(被覆ならそこで終了)、L212 を低商状態に適用する。

### `nonnegative_epoch_potential_drop_or_coverage` (L292)

**主張:** 非負エポックの総括: 被覆が得られるか、`n + q + 2` までに厳密に低いポテンシャルの実状態に達する。

**証明:** L107 で同レベルの低商へ降り、L148 の 2 歩の後処理で `G` を厳密に下げる。時間予算は商降下 `q` 歩+後処理 2 歩。

### `undershoot_epoch_trichotomy` (L315)

**主張:** undershoot 帯 `0 ≤ G(q,r) < m` の状態は `n + q + 2` 歩以内に三分岐する: (1) `CoverageStep m (a n) n`、(2) 負領域 `G < 0` への復帰、(3) 同じ帯のより低いレベル(`G` は厳密に下がり、なお `< m`)。

**証明:** L292 の厳密降下の到達点の符号で分ける。非負なら元のレベルより低くかつ `m` 未満のままなので (3)、負なら (2)。

### `undershootLevel_eventually_negative_or_localCoverage` (L346)

**主張:** レベル `g < m` の undershoot 状態からは、有限時間で `G < 0` の状態に達するか、後の時刻 `t` で局所的な `CoverageStep m (a t) t` を持つ状態に達する。

**証明:** 到達レベル `g` に関する強帰納法。三分岐(L315)で (1) なら現在時刻の被覆(これは `a n = a t` の形の局所被覆)、(2) なら負到達で終了。(3) なら新しいレベル `g' < g` が得られ、目標条件 `m ≤ t + 1` は時間の前進で保たれるので帰納法の仮定が適用できる。レベルは非負整数で毎回厳密に下がるため、この繰り返しは有限で止まる。

重要な注意として、(1) の被覆証明書は後の状態 `(a t, t)` に付く。これを元の初出親へ輸送するには値の比較(`a t < 親値`)が別途必要であり、それがこの層に残る大域証明上の論点である(L437 が正確に切り出す)。

### `undershoot_eventually_negative_or_localCoverage` (L387)

**主張:** レベルを明示しない利用者向けの形: `0 ≤ G(q,r) < m` から出発して同じ結論に達する。

**証明:** `g = r − U(q)` と置けば `G(q,r) = g < m` なので L346 に帰着する。

### `negative_undershoot_cycle` (L412)

**主張:** 負→undershoot の一周期。`G(q,r) < 0` から出発すると、元の状態で `CoverageStep m (a n) n` が得られるか、後の時刻 `t > n` の実状態で「`G < 0`」または「局所被覆 `CoverageStep m (a t) t`」が成り立つ。

**証明:** `NegativeEpoch.lean` の主定理で負エポックを処理する。被覆ならそのまま終了。undershoot 帯へ脱出したなら、その着地点に L387 を適用し、負復帰か局所被覆に達する。

### `negative_undershoot_cycle_coverage_or_parentGrowth` (L437)

**主張:** 一周期後の正確なフロンティア。`G(q,r) < 0` から出発すると、`CoverageStep m (a n) n` が得られるか、または後の時刻 `t > n` で `a n ≤ a t` を満たす実状態が「`G < 0` または局所被覆」の形で得られる。すなわち、解決されない周期は必ず出発値以上の値で戻ってくる。

**証明:** L412 の結果に対し、後の状態の値 `a t` を出発値と比較する。

- `a t < a n` の場合は、どちらの枝でも親の被覆に変換できることを示す。後の状態が負(`G(k,s) < 0`)なら `s < U(k)` から `k ≥ 1`(`k = 0` なら `G = s ≥ 0`)であり、`a t = t·k + s ≥ t ≥ n + 1 ≥ m`。`a t` の初出時刻を取れば、`m ≤ a t < a n` の初出値として `CoverageStep` の値下降枝が成立する。後の状態が局所被覆なら `mono_parent` で親へ持ち上げる。
- `a t ≥ a n` の場合は、そのまま「parent growth」(値が減らない再訪)として報告する。

したがって、値帰納を阻む唯一の形は「ポテンシャルは一周して下がった(または負に戻った)のに、通常の値は出発時以上に膨らんでいる」という再訪であり、この定理はその競合を正確に単離する。

## 全体の中での位置づけ

`NegativeEpoch` と `HistoryBudget` を入力とし、`HistoryFrontier.lean` と `CrossingRecovery.lean` から直接使われるほか、`CrossingGap.lean`・`PhaseEpoch.lean`・`OrbitReadyComplete.lean`・`NonnegativeSemantic.lean` がエポック定理群を再利用する。証明地図(docs/PROOF_MAP.md)の「非負帯有限化」に対応し、状況一覧の「非負帯 — 負領域復帰・Coverage・レベル下降」がこのモジュールの三分岐(L315)である。L437 が単離した「局所被覆の親への輸送」と「parent growth」の問題は、その後の三成分履歴ランク(`HistoryBudget`)・四成分位相ランク(`PhaseSearch`)が値以外の整礎量を導入して回避する動機となった。
