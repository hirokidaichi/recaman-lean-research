# OrbitBounds

**役割:** 実軌道の上界 `a n ≤ U(n)` と商の鋭い上界 `2q ≤ n+1` を証明し、実軌道上では多段借りが起こり得ないことを確定する。

## このモジュールの役割

`MultiBorrow` の算術モデルは任意回数の借り (borrow: 法変更に伴う商から剰余への繰り入れ) を許すが、実際のレカマン軌道がその一般性を必要とするかは別問題である。本モジュールは、歩幅の総和による自明な上界 `a n ≤ U(n)` (U は上三角数 q(q+1)/2) だけから商の上界 `2q ≤ n+1` を導き、多段借り (`b ≥ 2`) が要求する遠方領域 `q > n+1+r` が実軌道上では空であることを示す。結果として、実軌道の座標遷移は `CoordinateDynamics` の通常領域・一段借り領域の二種類で尽きることが確定し、証明地図の「多段借り: 解消済み」に対応する。

## 定理と証明

### `a_le_upperTri` (L6)

**主張:** すべての `n` について `a n ≤ U(n)`。

**証明:** `n` に関する帰納法。a(0) = 0 = U(0)。一歩では高々 `n+1` しか増えないので、減算・加算いずれの分岐でも `a(n+1) ≤ a(n) + (n+1) ≤ U(n) + (n+1) = U(n+1)`。

### `two_mul_upperTri` (L18)

**主張:** 除算を使わない閉形式 `2·U(n) = n(n+1)`。

**証明:** `n` に関する帰納法と展開計算。三角数を除算なしの再帰で定義した代償を、この等式で回収する。

### `CoordinatesAt.twice_quotient_le` (L34)

**主張:** 実軌道の座標点では `2q ≤ n+1`。

**証明:** まず剰余条件 `r < n` から `n > 0`。座標の等式 `a n = n·q + r` と `a n ≤ U(n)` から `n·q ≤ U(n)`。両辺を 2 倍して `two_mul_upperTri` を使うと `2·n·q ≤ n(n+1)`、すなわち `n·(2q) ≤ n·(n+1)`。`n > 0` で割って `2q ≤ n+1` を得る。商が時刻の約半分を超えないという、以降の解析で繰り返し使われる鋭い上界である。

### `CoordinatesAt.quotient_le_time` (L50)

**主張:** 特に `q ≤ n`。

**証明:** `2q ≤ n+1` から直ちに従う。

### `BorrowData.le_one_of_coordinatesAt` (L57)

**主張:** 実軌道の座標点における借りデータの借り回数は `b ≤ 1`。

**証明:** 仮に `b ≥ 2` なら `BorrowData.two_le_iff` により遠方領域条件 `n+1+r < q` が成り立つが、`quotient_le_time` の `q ≤ n` と合わせると `n+1+r < n` となり矛盾する。

### `BorrowData.eq_zero_or_one_of_coordinatesAt` (L68)

**主張:** 実軌道上の借り回数の正確な二分法: `b = 0 ∨ b = 1`。

**証明:** 前定理の `b ≤ 1` の言い換えである。用語集にいう「実際のレカマン軌道では b = 0 または b = 1 しか起こらない」の形式化そのものである。

### `not_far_chamber_of_coordinatesAt` (L75)

**主張:** 遠方領域は実軌道上で空である: 実座標点で `n+1+r < q` は成り立たない。

**証明:** `q ≤ n < n+1+r` から直ちに矛盾する。

## 全体の中での位置づけ

証明地図のモジュール層「局所遷移」の締めくくりであり、状況一覧の「実軌道上界 (証明済み)」と「多段借り (解消済み)」の両行を担う。これ以降のモジュールは、`MultiBorrow` の全域遷移 `coordinates_*_total` を実軌道に適用したとき、`eq_zero_or_one_of_coordinatesAt` によって借り 0 回 (通常遷移) と 1 回 (一段借り遷移) の二分岐だけを考えればよいことになる。負領域からの回復解析 (`Recovery` 系) は本モジュールを直接 import し、`2q ≤ n+1` の上界は高商障壁 (`RecoveryFrontier` など) の議論でも境界条件として機能する。
