# RecoveryBudget

**役割:** 一段借り遷移のポテンシャル収支(budget)を正確に計算し、非負着地・目標着地の条件を Nat 算術の同値式と有限の時刻窓に翻訳する。

## このモジュールの役割

`Recovery.lean` で負領域からの横断が一段借りに限られることが分かったので、本モジュールはその一段借りが `G` をいくら動かすかを厳密に計算する。鍵となる量は defect(欠損)`δ = q − r`、すなわち一段借り領域の壁 `r < q` からの距離である。一段借りの収支式は `δ` を使うと枝(加算・減算)に依存しない正規形になり、着地が非負になる条件・目標面 `G = m` にちょうど乗る条件が、三角数を含む Nat の等式・不等式と同値になる。さらに実軌道の鋭い商上界 `2q ≤ n + 1`(`OrbitBounds`)と組み合わせ、実軌道上の一段借りは加算・減算を問わず必ず `G` を厳密に増加させること、および目標面に着地できる時刻が幅 `q` の有限窓に限られることを示す。

## 主要な定義

### `addOneBorrowBudget` (L6)

一段借り加算のポテンシャル増分 `(n + 1) − q`(符号付き整数)。

### `subOneBorrowBudget` (L10)

一段借り減算のポテンシャル増分 `n + q`(常に非負)。

### `oneBorrowDefect` (L14)

defect `δ = q − r`。一段借り領域 `r < q ≤ n + 1 + r` の壁からの距離を表す自然数。

## 定理と証明

### `BorrowData.one_defect_spec` (L19)

**主張:** 借りデータが `b = 1` なら、`δ = oneBorrowDefect q r` は `0 < δ ≤ q`、`r + δ = q`、`s + δ = n + 1` を満たす。

**証明:** `b = 1` の領域条件 `r < q ≤ n + 1 + r` と収支式 `(n+1) + r = q + s` から直接計算する。`δ` は旧商を `r + δ = q` と分割し、新剰余を `s + δ = n + 1` と新しい法の補数に分割する。この二つの分割が以降のすべての計算の正規形になる。

### `oneBorrow_prePotential` (L38)

**主張:** 一段借りの直前のポテンシャルは `G(q,r) = −(T(q) + δ)`。ここで `T(q) = q(q−1)/2` は下三角数。

**証明:** `U(q) = T(q) + q` と `r = q − δ` を `G = r − U(q)` に代入する。負の深さが「下三角数+defect」に正確に分解されることを示しており、一段借り直前の状態が負領域のどの深さにいるかを座標だけで読み取れる。

### `oneBorrow_destination_nonnegative_iff` (L61)

**主張:** 一段借りの着地商が `k` のとき、`0 ≤ G(k,s)` ⟺ `U(k) + δ ≤ n + 1`。

**証明:** `G(k,s) ≥ 0 ⟺ U(k) ≤ s` と `s = n + 1 − δ` から従う。着地枝(加算か減算か)に依存しない統一判定式である点が重要で、回復の成否は「着地商の三角数と defect の和が新しい法を超えないか」だけで決まる。

### `oneBorrow_destination_target_iff` (L70)

**主張:** `G(k,s) = m` ⟺ `n + 1 = U(k) + m + δ`。

**証明:** `G(k,s) = m ⟺ s = U(k) + m` と `s + δ = n + 1` から従う。目標着地の「時計」であり、着地時刻が目標・着地商・defect で一意に決まることを示す。

### `add_oneBorrow_potential_eq` (L79)

**主張:** 一段借り加算(着地商 `q + 1 − 1 = q`)では `G(q, s) = G(q,r) + ((n+1) − q)`。

**証明:** `s = n + 1 + r − q` なので `G` の増分は `s − r = n + 1 − q`(商が変わらないため三角数の項は打ち消える)。

### `sub_oneBorrow_potential_eq` (L90)

**主張:** `2 ≤ q` のとき、一段借り減算(着地商 `q − 2`)では `G(q−2, s) = G(q,r) + (n + q)`。

**証明:** `s − r = n + 1 − q` と `U(q) − U(q−2) = 2q − 1` を合わせると増分は `(n + 1 − q) + (2q − 1) = n + q`。減算は商を 2 下げる分、三角数の閾値が大きく下がるため加算より増分が大きい。

### `CoordinatesAt.quotient_le_addOneBorrowBudget` (L104)

**主張:** 実軌道の座標では `q ≤ addOneBorrowBudget n q = (n+1) − q`。

**証明:** 実軌道の鋭い商上界 `2q ≤ n + 1`(`OrbitBounds` の `twice_quotient_le`)を移項するだけである。一般の算術モデルでは加算収支 `(n+1) − q` は負になり得るが、実軌道ではこの上界のおかげで必ず `q` 以上になる。

### `coordinates_add_oneBorrow_potential_lt` (L116)

**主張:** 実軌道上の一段借り加算は `G` を厳密に増加させる。

**証明:** 収支は `(n+1) − q ≥ q`(前定理)であり、一段借り領域では `r < q` から `q ≥ 1`。よって増分は正。

### `coordinates_sub_oneBorrow_potential_lt` (L129)

**主張:** 実軌道上の合法な一段借り減算も `G` を厳密に増加させる。

**証明:** 合法性から `n + 1 < a n`、よって `b + 1 ≤ q` すなわち `q ≥ 2`。また `r < n` から `n ≥ 1`。収支 `n + q > 0` なので増分は正。

一段借りは負領域内で唯一 `G` を上げる遷移であり、この二つの単調性が `OneBorrowFrontier.lean` の「ポテンシャル上昇を伴うフロンティア」を支える。

### `add_oneBorrow_nonnegative_iff` (L148)

**主張:** 一段借り加算の着地が非負 ⟺ `U(q) + q ≤ n + 1 + r`。

**証明:** 着地商は `q`、`s = n + 1 + r − q` を `U(q) ≤ s` に代入する。

### `sub_oneBorrow_nonnegative_iff` (L162)

**主張:** 一段借り減算の着地が非負 ⟺ `U(q−2) + q ≤ n + 1 + r`。

**証明:** 着地商 `q − 2` について同様。

### `add_oneBorrow_negative_iff` (L177)

**主張:** 一段借り加算が回復に失敗する(着地が負) ⟺ `n + 1 + r < U(q) + q`。

**証明:** L148 の否定。三角数 `U(q)` は `q` の 2 次で増えるため、失敗は商が時刻に対して大きい「高商」の場合に限られる。この閾値の具体的な帰結は `RecoveryFrontier.lean` が扱う。

### `sub_oneBorrow_negative_iff` (L185)

**主張:** 減算側の失敗 ⟺ `n + 1 + r < U(q−2) + q`。

**証明:** L162 の否定。

### `add_oneBorrow_target_iff` (L193)

**主張:** 一段借り加算が `G = m` に着地 ⟺ `n + 1 + r = q + U(q) + m`。

**証明:** 目標面の前状態の特徴づけ(`BorrowTargetPreimage`)に帰着する。左辺は現在の時刻情報、右辺は座標と目標だけなので、目標着地の可否が純粋に算術で判定できる。

### `sub_oneBorrow_target_iff` (L203)

**主張:** 一段借り減算が `G = m` に着地 ⟺ `n + 1 + r = q + U(q−2) + m`。

**証明:** 同様。

### `oneBorrow_target_time_eq` (L216)

**主張:** 一段借りが座標 `(k, G = m)` に着地するなら `n + 1 = U(k) + m + (q − r)` であり、`0 < q − r ≤ q`。

**証明:** 着地から `s = U(k) + m`、正規形 `s + δ = n + 1` に代入する。正のずれ `δ = q − r` が、着地時刻が目標時刻窓の内部のどこにいるかを正確に記録する。

### `add_oneBorrow_target_time_window` (L233)

**主張:** 一段借り加算が目標面 `G = m` に着地できる時刻は `U(q) + m ≤ n < U(q) + m + q` の幅 `q` の窓に限られる。

**証明:** L193 の等式 `n + 1 = U(q) + m + δ` に `1 ≤ δ ≤ q` を代入すると窓の両端が出る。固定した目標に対し、各商の一段借りが使えるチャンスは有限個の時刻に限られることを意味する。

### `sub_oneBorrow_target_time_window` (L244)

**主張:** 減算側の窓は基点 `U(q−2) + m`、同じ幅 `q`: `U(q−2) + m ≤ n < U(q−2) + m + q`。

**証明:** 同様。

## 全体の中での位置づけ

`Recovery` を入力とし、`RecoveryFrontier.lean` と `RecoveryWindows.lean` から使われる。証明地図(docs/PROOF_MAP.md)の「負領域 — 有限時間で一段借り」の後半、すなわち一段借りの定量解析にあたる。非負着地の閾値(L148, L162)は `RecoveryFrontier` の低商回復・高商 blocker 分岐の判定式に、目標時刻窓(L233, L244)は `RecoveryWindows` の exact gate・local escape 窓に、単調性(L116, L129)は `OneBorrowFrontier` と `NegativeEpoch` のポテンシャル上昇の主張に、それぞれ直接引き継がれる。
