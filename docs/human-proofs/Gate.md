# Gate

**役割:** 二回の連続した合法減算で目標 `m` へ正確に着地する局所配置「完全ゲート」の十分条件を証明する。

## このモジュールの役割

全射性予想の攻略では、目標値 `m` に軌道を正確に着地させる局所機構が必要である。本モジュールはその最も単純な機構、完全ゲート (exact gate: 必要な局所条件がそろえば二歩の減算で目標へ届く入口) を扱う。時刻 `u` の値がちょうど `2u + m + 3` で、中間値と `m` 自身がともに未出なら、次の二歩 (u+1 と u+2) は両方とも合法減算になり、正確に `m` に着地する。抽象的な `State` の上の主張なので、実軌道に限らずこの配置が現れた任意の場面で適用できる。

## 主要な定義

### `gateIntermediate` (L6)

完全ゲートの一歩目の着地点 `gateIntermediate u m = u + m + 2`。値 `2u+m+3` から歩幅 `u+1` を引いた中間値である。

## 定理と証明

### `exactGate_sufficient` (L12)

**主張:** `0 < m`、`state.value = 2u + m + 3`、`gateIntermediate u m ∉ state.seen`、`m ∉ state.seen` のとき、

```text
(step (u+2) (step (u+1) state)).value = m
```

すなわち時刻 u+1 と u+2 の二歩で正確に `m` に着地する。

**証明:** 二歩がともに合法減算であることを順に確認する。

一歩目 (時刻 u+1): 減算候補は `(2u+m+3) − (u+1) = u+m+2 = gateIntermediate u m` である。`u+1 < 2u+m+3` は常に成り立ち、中間値は仮定により未出なので `CanSubtract` が成立し、値は `u+m+2` になる。履歴には `u+m+2` が積まれる。

二歩目 (時刻 u+2): 減算候補は `(u+m+2) − (u+2) = m` である。正値条件 `u+2 < u+m+2` はちょうど `0 < m` と同値であり、これが仮定 `0 < m` の使いどころである。着地先 `m` が新しい履歴に含まれないことは、(i) 直前に積まれた中間値 `u+m+2` と `m` は `u+2 > 0` により異なる、(ii) 元の履歴に `m` はない、の二点から従う。よって二歩目も合法減算であり、値は `m` になる。

数値の設計を逆算すると: 二歩の減算の合計は `(u+1) + (u+2) = 2u+3` なので、出発値が `m + (2u+3) = 2u+m+3` であることが「二歩でちょうど `m`」の必要条件であり、本定理はそれに新鮮さ (freshness) の二条件を加えたものが十分条件であることを示している。

## 全体の中での位置づけ

証明地図のモジュール層「目標面」に属する。`Mechanisms` が本モジュールを import し、座標の言葉 (`G = m` の目標面上の状態) と接続して着地機構の一角を成す。中間値の未出条件が落とせないことは `Examples` の `targetSurface_two_fresh_target_but_blocked` が具体的に示している: 時刻 18 では目標レベル 4 自体は未出だが中間値 24 が既出のため、ゲートは開かず軌道は 62 へ跳ぶ。このように完全ゲートは「揃えば勝ち、揃わなければ blocker 解析へ」という被覆戦略の分岐点として機能する。
