## 攻撃と具体例

独立した検査は [元の出力](H-20260917-01_20260920_0100_output.txt) と
[再現用ファイル一式](H-20260917-01_20260920_0100_files/SHA256SUMS)に保存した。

  真の最古 S は phase 0、N(B)={4}。11>p なので同じ位相の再出現も実際に含む。

  N(B)={0,1,6} で緊密、past=w1、次符号=A。完全 U・最小 lag・Hall を独立に検査した。

  U={2,7,8,11,13}、donor=7、B={2,8,11,13}、N(B)={4,5,10,17} を再現。

  Q の SS 制限を落とした拡張は反証される。元の Q の反例ではない。

## 差戻しと残余

1. V1 の報告は初回試行を inclusive と記述していたが、実装は exclusive だった。
   [V1 無効化記録](../data/issue73_20260920/V1_INVALIDATED.md)を保存し、V2 で経緯を訂正した。
   初回 p=1..15 の失敗を p=1..11 の成功で置き換えていない。新規 holdout とも呼ばない。
2. 検査コードは違反数・適用数を表示するだけで、違反や対象0件でも exit 0 になり得る。
   終了コードは合格を強制しない。今回の合格は原ログの値と独立再現への限定判定である。
3. V2 の「詳細を出力する」という報告は一部過大。p8/p10 の制御行は選択した B、N(B)、次符号を
   全ては直接出力しない。詳細は独立の `validate_v2_controls.py` の assertions と出力で確認した。
   有限例の正しさは合格だが、worker 報告のこの表現は次回訂正対象として残す。
4. E-359 に渡す `b<p`、`e b=true`、P2、全 proper-prefix の非 P2 を、正式な完全 U・最小 lag の
   仮定から供給する必要がある。名前付き Prop や結論と同値な条件を追加して代用しない。
5. E-348 は整数 clock の位置一致を要求する一方、neighborhood は位相の同余を与える。
   周期 lift を省略しない。Nat の `u+2` にも周期境界の移送が必要である。
6. E-351 `aas_after_w1_forced` は既に `e(u+1)=true` と未来位相の U 所属・lag 3 を仮定する。
   これで W を証明したことにすれば循環である。
7. 周期性・U 完全性・Hall・最小性・lag 制限を一つずつ弱めるカード所定の検査は未完了。
   一般 Q/W の証明、donor を含む部分集合、一般 lag、一般 Gate T6、実軌道の全射性は結論しない。

有限探索の完全性の参照は `PeriodicSupplyBound.supply_lag_bound`、
正の `signSum` との橋は `ExactOrbitNonperiodicity.signSum_eq_period_mass`。
小例での有限回帰がこの橋や一般 Q/W の新しい証明になったわけではない。
