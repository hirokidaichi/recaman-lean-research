# RecoveryWindows

**役割:** 一段借りで exact gate(商 2)と local escape(商 3)の目標面に入れる時刻を、目標 `m` ごとの具体的な有限窓として確定する。

## このモジュールの役割

`RecoveryBudget.lean` の目標時刻窓定理は、一段借りが座標 `(k, G = m)` に着地できる時刻が幅 `q` の窓に限られることを一般形で示した。本モジュールはこれを、目標到達機構にとって特別な二つの着地商に特殊化する。商 2 は exact gate(完全ゲート: 二回の連続合法減算で目標へ正確に着地できる局所配置)の入口、商 3 は local escape(局所脱出: 強制加算を挟んで別の解析可能な配置へ移る機構)の入口である。三角数 `U(2) = 3`, `U(3) = 6` を代入すると、窓は `m` からの明示的なオフセットを持つ長さ 2〜5 の区間になる。負領域からこれらのゲートに入るチャンスが目標ごとに有限個の時刻しかないことを示し、ゲート機構の適用可能性を時刻の言葉で完全に有界化する。

## 定理と証明

いずれも `RecoveryBudget.lean` の窓定理(`add_oneBorrow_target_time_window`、`sub_oneBorrow_target_time_window`)に着地商の値を代入し、三角数を数値計算するだけの特殊化である。加算側の一段借りは商を変えない(`q + 1 − 1 = q`)ので旧商がそのまま着地商になり、減算側は商を 2 下げる(`q − 1 − 1 = q − 2`)ので旧商は着地商より 2 大きい。窓の幅は旧商 `q` に等しい。

### `add_oneBorrow_exactGate_time_window` (L7)

**主張:** 一段借り加算が exact gate の商 2 で `G = m` に着地するなら、`m + 3 ≤ n < m + 5`。

**証明:** 着地商 2 から旧商も `q = 2`。一般窓 `U(2) + m ≤ n < U(2) + m + 2` に `U(2) = 3` を代入すると幅 2 の窓 `[m+3, m+4]` を得る。

### `add_oneBorrow_localEscape_time_window` (L21)

**主張:** 一段借り加算が local escape の商 3 で `G = m` に着地するなら、`m + 6 ≤ n < m + 9`。

**証明:** `q = 3`、`U(3) = 6` を代入し、幅 3 の窓 `[m+6, m+8]` を得る。

### `sub_oneBorrow_exactGate_time_window` (L35)

**主張:** 一段借り減算が商 2 で `G = m` に着地するなら、`m + 3 ≤ n < m + 7`。

**証明:** 着地商 2 から旧商は `q = 4`。窓の基点は `U(q−2) + m = U(2) + m = m + 3`、幅は `q = 4` なので `[m+3, m+6]`。

### `sub_oneBorrow_localEscape_time_window` (L49)

**主張:** 一段借り減算が商 3 で `G = m` に着地するなら、`m + 6 ≤ n < m + 11`。

**証明:** 旧商は `q = 5`、基点 `U(3) + m = m + 6`、幅 5 なので `[m+6, m+10]`。

加算窓と減算窓は同じ基点(着地商の三角数 + `m`)を共有し、減算窓が加算窓を包含する形になっている。合わせると、商 2 のゲートに一段借りで入れるのは `n ∈ [m+3, m+6]` の高々 4 時刻、商 3 のゲートは `n ∈ [m+6, m+10]` の高々 5 時刻である。

## 全体の中での位置づけ

`RecoveryBudget` の直接の応用であり、証明地図(docs/PROOF_MAP.md)では回復層(`Recovery` 系)と目標面層(`Gate`, `Mechanisms`, `LandingSurfaces`)の接点にあたる。exact gate と local escape はそれぞれ `Gate.lean`・`Mechanisms.lean` で定義される到達機構であり、本モジュールはそれらの機構が負領域からの一段借り経由で起動し得る時刻を有限窓に限定する。現時点でこの窓定理を直接引用する下流モジュールはなく、ゲート機構の時刻解析を将来の局所被覆で使うための独立した境界データとして置かれている。
