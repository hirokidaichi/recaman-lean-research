# 最小SS2窓の最古Sと短い緊密集合 — 紙上議論

2026-09-20 15:23 JST。H-20260920-05。独立担当の監査前の証明草案。
以下は任意長の語の議論であり、長さ31までの計算を証明に使わない。
A=+1、S=-1、語は新しい時刻から古い時刻へ並べる。
`mass(w)=Σw_i`、`moment(w)=Σi w_i`、P2はmass=1かつmoment=0。
SSは重なりを含む隣接SSの数。

## 1. 末尾Aの不等式

SSがq以下で末尾がAの語Xでは、各接尾辞のmassが−q以上である。
最後の一文字Aだけはmass=1なので、momentが接尾辞massの和であることから

`moment(X) + q |X| >= q+1`。

既存Lean `mass_ending_A` が接尾辞massの下界を与える。
SS<=2で末尾がAAの語では、長さ2以上の各接尾辞massは−1以上、
最後のAのmassは1、最後のAAのmassは2だから
`moment(X)+|X| >=5`。

## 2. 中間語は短いP2を含む

**補題。** Xが末尾A、mass(X)=0、SS(X)<=2、moment(X)+|X|<=0なら、
XにはSで終わる真のP2接頭辞がある。

|X|で帰納する。末尾AAなら§1の下界と矛盾する。末尾SAなら
X=Y·SA。mass(Y)=0、moment(Y)+|Y|<=−3、SS(Y)<=2。
Yが末尾Aなら帰納仮定を適用する。Yが末尾SならX=Z·SSAで、
mass(Z)=1、moment(Z)<=−3、SS(Z)<=1となる。
Zが末尾Aなら既存 `lowSS_A_nonpositive_prefix` によりS終了P2接頭辞を持つ。
Zが末尾SならXはZの後にSSを加えるのでSSをさらに2消費し、SS(Z)=0。
既存 `zero_SS_nonpositive_prefix` を使う。空語のケースはmass条件と矛盾。
得られた接頭辞の後に少なくとも末尾Aが残るので真の接頭辞である。

## 3. AASの被覆を除く

WがP2、SS<=2で、最古Sの後の3時刻がAAAだとする。
Wより古い末尾部分はAだけであり、Wは

`W = X · AAS · A^v`

と書ける。XはAで終わる。donorの現在時刻がそのA以前なら、Wには
Sが一個しかなくSS=2に反するので、この分解のXは実際に非空。

v=0ならmass(X)=0、moment(X)+|X|=0、SS(X)<=2。
§2によりWにも真のP2接頭辞がある。よってWが最小なら不可能。

v>=1なら§1でmoment(X)+2|X|>=3。
一方moment(AAS)=0、mass(AAS)=1より

`0 = moment(W) = moment(X)+|X|+(|X|+3)v+moment(A^v)`。

右辺はmoment(X)+2|X|以上で、残りも非負だから矛盾。
この場合は最小性すら不要。

## 4. w1の最古Sを除く

w1=SAAAASSの最古SがWの最古Sと一致すると仮定する。
w1の現在符号はA。donorの現在時刻がw1の現在時刻以前なら、Wは
w1の接尾部分とそれより古いAだけで構成され、SS<=1になって矛盾。
従って、Aで終わる非空Xを用いて

`W = X · w1 · A^v`

と書ける。w1のSSは1なのでSS(X)<=1。§1からmoment(X)+|X|>=2。
w1自体はP2なので

`0 = moment(W) = moment(X)+|X|+(|X|+7)v+moment(A^v) >=2`、矛盾。
この排除にはWの最小性もdonor現在符号Aも不要。

## 5. 短い緊密集合への帰結と限界

H-01/E-357により短いOwnerFamilyのメンバーはAASかw1である。
w1のS offsetsは1,6,7。offset1でdonor最古Sを覆う場合、H-02の
未来AASメンバーから最古Sの次の3符号がAAAとなり§3に反する。
offset6でもw1自身の内部に同じAAAがある。offset7は§4に反する。
AASの被覆は直接§3で除かれる。

従って、**任意長の最小P2・SS=2 donorの最古Sは、短いOwnerFamilyの
どのメンバーにも覆われない**。周期的な緊密集合は既存のHall liftで
OwnerFamilyになり、非最小の短いB窓はH-03の接頭辞縮約を使える。
これにより短いBについて任意長の最小SS2 donorの削除が可能になる。

ここで「短い」はBの各P2窓の長さ<=11という意味で、donorの長さ制限はない。
任意lagを含むB、全供給集合のHall、Recamánの全射性はこの議論の外である。
長さ15の非最小donor反例は§3のv=0で真のP2接頭辞を持つ場合に一致し、
本議論を反証しない。周期性・正の周期質量を§1〜4は使っていない。
