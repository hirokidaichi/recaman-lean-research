## 2. C2: 実装の検査範囲

1. `G(b)−G(t)−(b−t)F(t) = Σ_(t,b](F(u)−F(t))`
   `= Σ_[t,b) σ(c)(b−c)`。有限和の順序を入れ替えると各σ(c)の出現回数がb−cとなる。
   よって旧probeの`isw`は直接のmass/moment条件と同じ。終点のA条件は別に検査される。
2. `LeadingRunSupply.p2_count_identities`は `L=2·ones−1` と `ones % 2=0`、
   `p2_length_ge_three`はL≥3を与える。従ってL≡3 mod4で、t=b−3,b−7,…の走査は全P2候補を含む。
   これは既存Lean定理の適用で、新しい一様なC2の証明ではない。
3. `dfsw`は非負なdのprefixを全分岐し、d(q0)=1でのみyへ入り、`lastz`を更新して最後の零点を渡す。
   `dfsy`の`nay`は基点pのまま非Endable Aを数える。AYMAX=1,YDMIN=1の実行を照合対象とする。
4. 各再帰の入場時はd(b)≥1だが、候補の判定は`nd<1`による枝刈り前。
   EndableなAではnd=d(b)−1なので、d(b+1)=0の終端も検査する。
   v1はb+1まで正を要求するため、この点でprobeは広い母集団を検査する。
5. c3.cの`if(mid)`は局所窓の併存も許し、mid窓の最大長>3を検出する。
   c2.cの`!any && mid`は局所窓のないはみ出しだけを扱う。
   c3.cの`withS`という出力名は長さ>3の件数であり、Sの有無ではない。
6. 入力はp=0へ平行移動して対応する。q0≤LW、b−q0<LYの範囲のみを検査する。
   配列アクセスには正のLW/LYかつLW+LY≤256が必要（旧報告33+48はこの範囲）。
   整数・counterのoverflowを含め、具体的な旧出力の信頼性は別の監査事項。

Dからv1の仮定への供給は、既にカードへ記したb+1<k、同じ基点でのaの単調性、
Dの内部正値性で確認できる。D自体を最小反例から供給する補題T/Fは別の未監査義務。
旧報告のC2′検査のraw logを特定できなかったため、その「違反0」の数値は今回追認しない。

## 3. C2: 長さ3の結論が持つ意味

v1の仮定を満たすmid窓の長さが3なら、mass=1からA二つ・S一つ。
moment=0はSの重みが3であることを要求するので、前向きにSAAである。
t<q0≤bより[q0,b)はその末尾のA列の部分。Endableなb自身も含めて
[q0,b+1)にはSがなく、Endableは少なくともbの一つだから

`d(b+1)=d(q0)+#S[q0,b+1)−#Endable_p[q0,b+1)≤1+0−1=0`。

これはv1のd(b+1)≥1と矛盾する。従ってv1の正値設定では、長さ3のmid窓は起こらない。
残る可能性は長さ≥7の窓であり、それを排除する一様な数学的入力が未発見。
「全mid窓が長さ3」という候補を証明できれば、この設定ではmidそのものの不存在を与える。
この言い換えを新しい進捗や証明として数えない。

端点の確認にも使える。`F(u)=F(q0)+a_p(q0,u)+1−d(u)` より内部ではF(u)≤F(q0)+1。
Endableなbでd(b+1)≥1ならd(b)≥2なのでF(b)≤F(q0)。
三つ組切断例はF(b)=F(q0)+1、d(b+1)=0で、この境界を実際に区別する。

## 4. C1: Pの供給元を閉じる紙上chain

問いはDの下でPを供給するのに、全区間Hや新しい仮説が必要か。合格は短いEqClassWと
既存E-378まで依存を展開すること。新しい実験・修理・Lean実装は行わない。

`d(k1)=0` だけでEqClassWを直ちに適用してはならない。最後のclockがEndableとは限らない。

- k1=pならPのtの範囲は空。
- [p,k1)にEndableがなければ、d(k1)=0からSもない。従って全てAである。
- Endableがあれば、その最後をvとする。[v+1,k1)にはEndableがないので
  `0=d(k1)=d(v+1)+#S[v+1,k1)`。
  Dのprefix非負性によりd(v+1)≥0、Sの数も非負だから、両者は0である。
- [p,v+1)は等号かつ最後がEndableで、v+1≤k1<q0<kなので真部分区間。
  Dの短いEqClassWからそこはブロック語β。[v+1,k1)にはSもないから、全体はβ A^aとなる。
- E-378 `block_suffix_positive_walk`を使えば、各p≤t<k1について
  `F(k1)−F(t)≥1` と `Σ_(t,k1](F(u)−F(t))≥1`、すなわちPが得られる。

境界監査: Endableなし、末尾Aが0個、k1=p、v=k1−1を個別に扱った。
非負性を落とすと、抽象ledger上ではd(v+1)=−1と末尾S一個が相殺し、末尾全Aは導けない。
これは弱化した簿記の反例で、実際の符号語やHの反例だとは主張しない。

P2(t,b)を仮定するとPのmassからF(b)=F(t)+1≤g=F(k1)。
面積をk1で分ければ、Pのarea≥1とQのZ(b)≥0によりmoment≥1となり、P2のmoment=0と矛盾する。
よってDでPの供給を確認した後の未知edgeはQである。**Qは今回も証明していない。**
このchainは既存の条件付き帰着の意味監査で、新規研究用のwrapperモジュールにしない。

## 6. TS: 始点数mだけでは足りない（紙上の反例）

診断の問いは、全始点を数える方向へ移るとき、mだけで次のEndable判定を更新できるか。
新しいCPU探索は行わず、小さな語を直接定義で検算した。TSそのものの反例ではない。

接頭辞uで各始点t≤uについて `D_t=F(u)−F(t)`、
`W_t=Σ_(t,u](F(v)−F(t))`、`Q_t=W_t+D_t(D_t−1)/2` とする。
Q_tはTSの旧sourceで使う座標であり、C1の面積不等式Qとは別の記号。
Endable(u)は、次の符号がAかつ、t<uで状態(D_t,Q_t)=(1,0)があることと同値。

**候補M0（REFUTED）**: 長さu、現在高さF(u)、不足d(u)、
`m(u)=#{t∈[p,u]:D_t(u)=1}`、次の符号が一致すれば、次のEndable判定も一致する。

反例はp=0、u=4での二つの接頭辞 `ASAA` と `AASA`、次の符号はいずれもA。

| 接頭辞 | F(0),…,F(4) | d(4) | D=1の始点 / Q_t | Endable(4) |
|---|---|---|---|---|
| ASAA | 0,1,0,1,2 | 1 | t=1,3 / Q=0,1（m=2） | 真: [1,4)=SAA、moment=−3+2+1=0 |
| AASA | 0,1,2,1,2 | 1 | t=1,3 / Q=2,1（m=2） | 偽: [1,4)=ASA、moment=3−2+1=2 |

両語ともu<4のEndableはなく、Sは一つだからd(4)=1。長さ・高さ・不足・mは同じ。
後者は長さ3以外の窓についても、長さ1はmoment≠0、長さ2/4はmass≠1で除外できる。
従ってこれは実際の符号語によるM0の反例で、自由な抽象状態だけのcountermodelではない。

全始点の有限支持histogram `H_u(D,Q)=#{t∈[p,u]:(D_t,Q_t)=(D,Q)}` なら、正確な更新は

```text
A: H_(u+1)(D,Q) = H_u(D−1,Q−2D+1) + 1_{(D,Q)=(0,0)}
S: H_(u+1)(D,Q) = H_u(D+1,Q)       + 1_{(D,Q)=(0,0)}
```

古い始点にはAで(D,Q)→(D+1,Q+2D+1)、Sで(D,Q)→(D−1,Q)を適用し、
新しい始点u+1を(0,0)に一つ加えるためである。次のEndable判定はAかつH_u(1,0)>0。
一方mの更新にはD=0やD=2の始点数も必要で、mだけでは閉じない。

このhistogramは全履歴を持つ表現で、状態数は一様に有限とは限らない。これを新しい不変量やTSの証明と呼ばない。
Endableの判定・遷移だけなら、全(D,Q)状態の集合でも、同じ写像と(0,0)の追加で正確に更新できる。
従ってこの反例から「多重度が必須」「Qの全分布が必須」までは結論しない。
示したのはmだけではQ=0の有無を区別できないこと。既知の漏れの鎖をmだけに潰す案は停止し、
次は必要なQ情報を保つ集約量を候補にする。その集約量とslackを結ぶ非自明な不等式は今回得られていない。
