E675の幾何重み3による上界とE702の無重み化no-goは既存入力であり、新進展に数えない。新規部分は、正確な臨界値、全非幾何的profileを含む有限高さの最適偏り、固定倍率ごとの正確な指数、および全primal基底をprefix/return付き歩みに運ぶ構成である。H-20261125-02の提案・範囲・反証条件は計算前に固定した。途中のH=0歩み境界修正と、より強い基底構成の追加はカードに時刻を付して残した。

## 1. 量化する会計と、量化しない実source

任意の整数H>=0に対して、0<=h<=Hの非負整数A_h,E_h,F_hが

    A_h=E_h+F_h,
    E_h <= sum_(t=0..h-2) (2(h-t)-3) A_t                 (K)

を満たすconeを考える。空和は0。K_d=0 (d<2)、K_d=2d-3 (d>=2)と置く。有限下三角行列Kの成分はK_(h,t)=K_(h-t)。E674の適切な元履歴はこの必要式を供給するが、逆向きは証明されていない。以下の「供給」はこの節ではEという宣言数である。

正の実重みw_0,...,w_Hと実C>0に対して、すべての上記整数入力で

    sum_h w_h A_h <= C sum_h w_h F_h                     (B)

となることを重み付きcapacityと呼ぶ。F_hの実source不在性を新しいProp入力にするadapterではなく、必要式だけから得られる能力の限界を定める問いである。

## 2. 全整数入力を尽くす正確な双対条件

有限逆行列R=(I-K)^(-1)=I+K+...+K^Hは非負整数成分を持つ。Toeplitz係数r_nを

    r_0=1, r_1=0,
    r_n=sum_(d=2..n) K_d r_(n-d)

で定義するとR_(h,t)=r_(h-t) (h>=t)。最初は1,0,1,3,6,13,29,...である。(I-K)A<=Fを非負行列Rに掛ければA<=RF。従って(B)の必要十分条件は、すべての0<=t<=Hで

    sum_(h=t..H) w_h r_(h-t) <= C w_t.                  (D)

十分性は上の成分比較と非負Fの和から従う。必要性にはF=e_t, A=Re_tを使う。E=A-F=KAは非負整数なので、これは実際にconeの入力である。有限の一つの飽和例を調べただけではなく、すべての整数入力に対する必要十分条件を得た。

形式的母関数では

    K(z)=z^2(1+z)/(1-z)^2,
    R(z)=1/(1-K(z))=(1-z)^2/(1-2z-z^3).

したがってr_n=2r_(n-1)+r_(n-3) (n>=3)。この等式は形式的冪級数の係数比較であり、収束を前提にしていない。特にr_n>=2^(n-2) (n>=2)。

## 3. 幾何重みの臨界値と最良倍率

任意のq in(0,1)について、すべての高さHに共通の有限Cでw_h=q^hの(B)が成立する必要十分条件は

    kappa(q):=q^2(1+q)/(1-q)^2 < 1.

このとき最良のCは1/(1-kappa(q))である。kappa<1の十分性は有限和を拡張してEの重み和<=kappa*Aの重み和とするだけでも得られる。ただしここから先の必要性・最良性は別に示す。

qstarをq^3+2q-1=0の(0,1)内の唯一の根、rho=1/qstarとする。多項式はこの区間で厳密増加し両端で符号が違う。rhoはrho^3-2rho^2-1=0の唯一の正根で、11/5<rho<221/100。これは有理端点での符号検査と、1-2/rho-1/rho^3の厳密増加による。

g_0=g_1=1、g_h=sum_(t<=h-2) K_(h-t)g_t (h>=2)と置く。g=R(e_0+e_1)であり、g_2=1,g_3=4、g_h=2g_(h-1)+g_(h-3) (h>=4)。h=1,2,3で直接比較し、rho^3=2rho^2+1を用いて帰納すれば

    rho^(h-2) <= g_h <= rho^(h-1)      (h>=1).           (G)

q<qstarなら(G)によりsum g_h q^hが収束し、非負和の畳み込みまたは収束した母関数により

    sum_(h>=0)g_h q^h=(1+q)/(1-kappa(q)).

有限Hまで切ったgはF_0=F_1=1、他のF=0という整数入力である。有限比がこの値へ近づくので、Cを1/(1-kappa)より小さくできない。q=qstarでは各h>=1の項g_h q^h>=rho^(-2)、q>qstarならさらに大きい。従って有限比はHとともに発散し、一様な有限Cは存在しない。有限計算の「反例なし」から臨界点の結論を出していない。

簡単な全profileの必要条件として、任意の正重みで(B)なら

    max(w)/min(w) >= g_H/(2C) >= rho^(H-2)/(2C) (H>=1).

実際、min(w)g_H<=w_Hg_H<=C(w_0+w_1)<=2C max(w)。これは幾何重みに限らない。しかし固定Cについては次節がさらに鋭い。

## 4. 固定倍率Cでの、全profileを含む有限高さの最適値

H>=2ではC<=1の(B)を満たす正重みは存在しない。C<1はA=F=e_Hで失敗し、C=1はt=0の(D)にある正項w_2 r_2で失敗する。以下C>1、a=C-1とする。

    v_0=v_1=1,
    v_n=max(1, a^(-1)sum_(d=2..n)r_d v_(n-d)).          (V)

すべての正重みのうち、capacity Cを満たすものの最大重み/最小重みの**正確な最小値**はv_Hである。

証明：min(w)=1に正規化する。(D)から

    w_t >= max(1, a^(-1)sum_(d=2..H-t)r_d w_(t+d)).

後ろからの帰納でw_t>=v_(H-t)、従ってmax(w)>=v_H。逆にw_t=v_(H-t)とすれば(V)がそのまま(D)を与える。v_nは非減少：直前のvの単調性とr_d>=0から畳み込み和が非減少となることを帰納し、max(1,...)を取る。従ってこの重みの最小値は1、最大値はv_H。下界が達成された。有限高さでCが大きくv_H=1となる場合もmaxを落としていない。

指数も正確に定まる。rho_Cを

    a rho_C^3 - 2a rho_C^2 - rho_C - C = 0

の唯一の正根とする。q_C=1/rho_Cはkappa(q_C)=1-1/Cを満たすので0<q_C<qstar、従ってrho_C>rho>2。

v_n>=r_n/aより、十分大きいnでは(V)のmaxは畳み込み側となる。f_n=v_n-a^(-1)sum_(d=2..n)r_d v_(n-d)>=0と置くと、f_0=f_1=1でfは有限supportを持つ。形式的母関数は

    V(z)= a(1-2z-z^3) f(z) / (a-2az-z^2-Cz^3).

従って十分大きいnについて、すべて正の係数を持つ漸化式

    v_n=2v_(n-1)+a^(-1)v_(n-2)+(C/a)v_(n-3)            (R)

が成立する。初期の有限個の正値v_j/rho_C^jの最小値m_C>0、最大値M_C<infinityを取る。(R)とrho_Cの方程式から、その後も同じ二値の間に保たれる。よって全nでm_C rho_C^n<=v_n<=M_C rho_C^n。特にlog(v_H)/H -> log(rho_C)。

**E675のC=3/2は非幾何的profileを含め指数3が最適。** この場合a=1/2、rho_C=3、vの最初は1,1,2,8,22,66,200。n>=2でmaxはinactiveなのでf(z)=1+z、(R)はn>=5から成立する。n=2,3,4を調べ、正係数による帰納を行うと

    (2/9)3^H <= v_H <= (8/27)3^H       (H>=2).

幾何重み3自体は旧E675である。今回の新しい否定対象は「同じcapacity3/2のまま、非幾何的重みへ変えれば指数3より遅い偏りにできる」という全profileの方法である。

## 5. 全prefix・実単位歩み・returnを保つ原始基底の輸送

上の最適値が単に段の整合性を忘れた結果ではないかを攻撃する。固定H>=2、t in[0,H]、整数M>=1に対し、rの負添字を0として

    alpha_h=1+M r_(h-t),
    phi_h=1+M*[h=t],
    epsilon_h=M(r_(h-t)-[h=t]).

高さ0からHへ順に、各stage hで(AS)^(alpha_h-1)Aを歩く。stageの供給markはepsilon_h個、free markはphi_h個（freeを先に並べてよい）。すべてのstageが終わったらS^(H+1)で床へ戻る。これに初期S^(H+2)と末尾AAを付ける。最後のAAはfreeと宣言する。

高さは初期head後の床を相対0とする。stage hのA始点はすべてh、coreの各edge hは上へalpha_h回、下へalpha_h回通る。最後AAによりedge0,1の上昇が一回ずつ追加される。元絶対高さはcore中で高々-1、最後も-H<=-2。したがって**すべての非空の元prefix**でS-A>=1、従ってS-epsilon>=1。初期headは正確にH+2で、終端高さは2-(H+2)、所定returnも満たす。後から基点をresetしていない。

各stage hを開始する前にすべての低いstageが完了している。rの定義からepsilon_h=M sum_(s<h)K_(h-s)r_(s-t)<=sum_(s<h)K_(h-s)alpha_s。stage h途中の供給数はepsilon_h以下なので、同じ基点の**すべてのprefix**で(K)が成立する。head/下降中は供給数が増えない。末尾AAはfreeのみで低いAを増やすから不等式を壊さない。

最終countsはA=alpha+e_0+e_1、F=phi+e_0+e_1、E=epsilon。この歩みの重み付き(B)の左辺−右辺は、delta_t=sum_(h=t..H)w_h r_(h-t)-Cw_t、B_0=sum_h w_h+w_0+w_1と置けば

    M delta_t -(C-1) B_0.

従って(D)のどれかがdelta_t>0で破れるなら、M>(C-1)B_0/delta_tを満たす整数を選ぶことで有限の歩み反例を得る。このclassのすべての歩みにcapacityを要求すれば、Mで割って極限を取るだけでも(D)の必要性が従う。逆の十分性はcone全体の定理による。よってこの全prefix/flow/return緩和classでも、第4節の**正確な最小偏りv_H**が必要十分である。

さらに、固定したH・初期head・重みに依存する任意の有限加法境界費用beta(H,m,w)>=0を(B)の右辺へ足しても、betaがMに依存しない限り(D)の必要性は変わらない。上の反例ではM>( (C-1)B_0+beta )/delta_tと選べるからである。深さやheadだけの境界補正を無視したのではなく、同じheadのまま増幅して支払い能力を尽くした。元actual freeやseed-stockの費用がMとともに増える場合はこの否定の対象外であり、E772の数値stock境界を反証したことにはならない。

これは元source時計・面積条件を内部生成した証明ではない。歩みは実在するがepsilonは宣言であり、元EndNとの差がある。数値位置の正値性やgreedy freshness、canonical前史への到達性を追加してこの反例が通るとは主張しない。

## 6. 元actualを混ぜない負対照

より小さいg構成（stageのA数g_h、初期S^(H+2)、core下降、最後AA）では、H>=1で宣言freeは4。全prefix必要式とstrict deficit、returnは上と同じ理由で成立する。H=0は最後AAが絶対高さ0に到達してしまうため、この歩み主張の範囲から除外した。

H=3では、最初のheadはS^5、Aのstage数は1,1,1,4。stage3の最初Aの元clockは8で、宣言では供給済み。しかしsource候補の高さにある元clockは3と7だけで、元窓の面積はそれぞれ-3と1。どちらも0でない。このAは元freeである。すべてのsource時計を保持したforward-prefix和と独立reverse加重和の双方で同じ不一致を確認した。全語の宣言E=5/F=4に対して元actual E=2/F=7。H=4では宣言E=14/F=4に対して元actual E=2/F=16。宣言free4を元free4と書くことはできない。

この負対照があるため、元倍率3/C1をREFUTEDへ変更しない。大きい低stageの山頂も実sourceになる。基底輸送のH2/a=(7,1,7)では元actual E=3、宣言E=6であり、「一stageに実供給は一件まで」という探索中の案は誤りだった。後続の実source分類ではこの峰のbankを必ず保持する。今回REFUTEDなのは必要会計だけで指数偏りを回避する方法であり、完全な任意Hのno-goの証拠は上のPAPER構成に置く。
