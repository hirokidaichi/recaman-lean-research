# InitialRegion

**役割:** 任意の正の目標 `m` について、時刻 `m−1` または `m` に「エポック解析を開始できる状態」が必ず存在することを、小さい目標の列挙なしに一様に証明する。

## このモジュールの役割

符号エポック (epoch: 同じ符号条件のもとで追跡する有限な軌道区間) の定理群は、目標 `m` に対して「時刻条件 `m ≤ n+1`、値の下界 `m ≤ a n`、正準座標、現在値の初出時刻」がそろった開始状態を前提にする。本モジュールは、その開始状態が全ての目標について実在することを証明する。鍵は、時刻 `m−1` の値が目標未満なら、次の一歩は歩幅 `m` の強制加算となって必ず目標を追い越す、という自己回復的な観察である。これにより、探索の入口が目標ごとの個別検証なしに一様に確保される。

## 定理と証明

### `exists_targetReady_state` (L13)

**主張:** `2 ≤ m` のとき、次を満たす `n, q, r, f` が存在する:

```text
n = m−1 または n = m
m ≤ n+1
m ≤ a n
CoordinatesAt n q r
f ≤ n かつ FirstAt a (a n) f
```

すなわち、時刻 `m−1` か `m` のどちらかで、値が目標以上、時刻条件 `m ≤ n+1` を満たし、正準座標 (CoordinatesAt: `a n = n·q + r`, `r < n`) と現在値の初出時刻 (FirstAt: その時刻に値を取り、それより前には取らない) を伴う状態が取れる。

**証明:** `m ≤ a(m−1)` かどうかで場合分けする。

場合 1 (`m ≤ a(m−1)`): `n = m−1` を取る。`m ≥ 2` より `m−1 > 0` なので `exists_coordinatesAt` が座標を与え、現在値は履歴に含まれる (`current_mem_valuesThrough`) から `history_member_has_firstAt` により初出時刻 `f ≤ m−1` が得られる。時刻条件は `m ≤ (m−1)+1` で等号成立。

場合 2 (`a(m−1) < m`): 時刻 `m` の一歩は歩幅 `m` の減算を要求するが、減算の合法性には `m < a(m−1)` が必要なので減算できない。よって強制加算になり `a m = a(m−1) + m ≥ m`。そこで `n = m` を取れば値の下界が成り立ち、`m > 0` なので座標が存在し、初出時刻も場合 1 と同様に得られる。時刻条件は `m ≤ m+1`。

どちらの場合も、返される時刻が `m−1` か `m` のいずれかであることが選言 `n = m−1 ∨ n = m` として明示される。目標未満に沈んでいた軌道が、ちょうど目標と同じ歩幅の強制加算によって自動的に目標以上へ押し上げられる、という一点にすべてが掛かっており、小さい `m` の列挙が不要になる。

### `exists_targetReady_state_of_pos` (L52)

**主張:** 同じ結論が `0 < m` だけで成り立つ。

**証明:** `2 ≤ m` なら前定理そのままである。残るのは `m = 1` のみで、このときは時刻 `n = 1` を直接の証人にする: `a 1 = 1 ≥ 1` は `decide` による計算で確認でき、座標と初出時刻は前定理と同じ一般補題から得られる。時刻条件は `1 ≤ 2`。

## 全体の中での位置づけ

証明地図のモジュール層「初期領域・canonical閉包」の起点である。`PhaseSearchStart` は本モジュールの目標準備状態から四成分位相ランクの探索を開始し、`CrossingGap` も import している。状況一覧の「canonical開始 (局所閉包済み)」で扱う canonical 開始点とは、まさにここで構成される状態に符号 (ポテンシャルの正負) とレベルの分類を重ねたものであり、`CanonicalOracle` 系のモジュールがその全分岐を閉じる。すなわち本モジュールは、大域探索という機械に最初の燃料 (どの目標にも存在する開始状態) を供給する役割を持つ。
