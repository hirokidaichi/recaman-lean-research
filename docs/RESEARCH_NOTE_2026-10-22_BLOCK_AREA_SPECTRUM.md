## 正確な主張

`BlockWord=(A | B | C)*`、B=SAAA、C=SSAAAASAAAとする。
語wについてm=mass(w)=#A−#S、
`areaW(w)=Σ_{i=1}^{|w|} mass(w.take i)`と定義する。
整数mに対して、同じ語から得られる面積の集合を

```text
S_m = { areaW(w) | BlockWord(w), mass(w)=m }
```

と置く。負のmでは空、S_0={0}、S_1={1}。
任意の整数m≥2について

```text
S_m = { z∈Z | L_m ≤ z ≤ U_m }
L_m = m(m+1)/2 − 1
U_m = floor((5m²−11m+16)/4).
```

これは「その区間の各整数について具体的なBlockWordが存在する」という方向も含む。
各clockの異なる面積候補を**同じ一つのprefixで同時に実現できる**とは述べていない。

## 再帰の両方向

空でないブロック語は最後のatomがA/B/Cのいずれかであり、取り去った語もBlockWordである。
面積のappend恒等式は、元語のmassをxとすると

```text
A: mass +1, area +(x+1)
B: mass +2, area +(4x+2)
C: mass +4, area +(10x+9).
```

従ってm≥1で、負添字の集合を空として

```text
S_m = (S_(m−1)+m) ∪ (S_(m−2)+4m−6) ∪ (S_(m−4)+10m−31).
```

左から右は最後のatomを消す操作、右から左はそのatomをappendする操作である。
文法は各atomのmassが正なのでmass0の語は空語だけ、mass1の語はAだけである。
再帰は有限massの帰納に使え、未知の容量HやQを仮定しない。

## 小さいmassを省略しない

再帰を直接展開すると次の集合が得られる。角括弧は両端を含む全整数。

| m | S_m | A/B/Cからの寄与 |
|---|---|---|
| 0 | {0} | 空語 |
| 1 | {1} | A |
| 2 | [2,3] | {3}, {2}, 空 |
| 3 | [5,7] | [5,6], {7}, 空 |
| 4 | [9,13] | [9,11], [12,13], {9} |
| 5 | [14,21] | [14,18], [19,21], {20} |
| 6 | [20,32] | [20,27], [27,31], [31,32] |
| 7 | [27,46] | [27,39], [36,43], [44,46] |

全て上記のL_m/U_mに一致する。mass0/1へm≥2の式を適用するのは誤りである。
例えばm=1で式だけを見るとarea0も許すが、実語はAのarea1のみ。

## m≥8の帰納段

P(m)=5m²−11m+16と置く。mより小さい正のmassで主張が成立するとする。
三つの寄与は整数区間

```text
I_A = [L_(m−1)+m,       U_(m−1)+m]
I_B = [L_(m−2)+4m−6,    U_(m−2)+4m−6]
I_C = [L_(m−4)+10m−31,  U_(m−4)+10m−31]
```

となる。三つの左端は順に

```text
L_m,
(m²+5m−12)/2 = L_m+2m−5,
(m²+13m−52)/2 = L_m+6m−25
```

である。m≥8なのでこの順に増え、I_Aの左端はL_m。
またP(m−4)+4(10m−31)=P(m)なので、I_Cの右端はちょうどU_mである。

残るのは整数区間の隙間がないこと。整数nで
`floor(P(n)/4) ≥ (P(n)−3)/4`を使うと

```text
4*(right(I_A)+1−left(I_B)) ≥ 3m²−27m+57,
4*(right(I_B)+1−left(I_C)) ≥ 3m²−41m+139.
```

一つ目の右辺はm=8で33であり、mを1増やす差は6m−24>0。
二つ目はm=8で3であり、差は6m−38>0。
従って両方ともm≥8で正で、特に

```text
left(I_B) ≤ right(I_A)+1,
left(I_C) ≤ right(I_B)+1.
```

よって三区間の和集合はL_mからU_mまでの全整数を含む。
各区間の整数は帰納仮定の語へ最後のatomを付けて実現できる。
反対に、どの語もE-381のLean確認済みの二次下界・上界を満たすので区間外には出ない。
これで両方向が閉じる。

## 次にLean化する最小義務

既存E-381が必要方向を与えるので、存在方向だけを次の独立statementとして実装する。

```text
∀ m:Nat, 2≤m → ∀ z:Int,
  (m:Int)*((m:Int)+1) ≤ 2*z+2 →
  4*z ≤ 5*(m:Int)^2−11*(m:Int)+16 →
  ∃ w:List Bool, BlockWord w ∧ mass w=(m:Int) ∧ areaW w=z.
```

Natの強帰納で、小さいmassを上記の完全な集合へ分け、m≥8では三区間のどれに入るかを選ぶ。
選んだ区間からoffsetを引いたareaに帰納仮定を使い、最後のatomをappendする。
Natのm−4の切り捨てが紛れないよう、その枝ではm≥8を先に固定する。
