## 検証

- `plain` の出力は、dense bitset の `near_diagonal_rate_probe`（3×10^9）と共有列（clocks、interior、
  subDiagonal、height ≤ 1356、height 1357..4095、minHeight@clock）が全 decade で一致した。
- `accel` と `plain` の stdout は 10^9、3×10^9、10^10 で（時間と区間統計の行を除き）**同一**。
  `accel` を時刻 1 から使う `accel0` も同一。
- OEIS A057167 の照合：19 の初出は 99734、**1355 の初出は 325,374,625,245**（一致）。
  mex の推移：2 (1), 4 (4), 19 (131), 61 (99734), 879 (181653), 1355 (328002),

## 高さ帯 [1, K] への chain の段数（entries）

entry は「時刻 n の高さが [1, K] にあり、直前の時刻の高さが帯の外」の時刻で、chain の内部では
interior と exterior が交互に来るため、帯を通過する chain 1 本につき約 K/3 件が数えられる。
K = 1024 の列（341 = 1023/3 の倍数で現れる）:

| decade | entries (mod 3 = 0 / 1 / 2) | 帯を掃いた chain 本数 |
|---|---|---|
| 1e8 | 0 (0/0/0) | 0 |
| 1e9 | 341 (0/0/341) | 1 |
| 1e10 | 682 (0/0/682) | 2 |
| 1e11 | 1705 (682/0/1023) | 5 |
| 1e12 | 1023 (682/0/341) | 3 |

mex 1355 → 2406 の遷移（3.25×10^11、剰余 0 の chain）はこの表の 1e11 行の剰余 0 の chain に対応する。
