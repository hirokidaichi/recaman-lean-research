# 第三S対象の供給飽和は成立しない

**E-590 PROVED-PAPER。** 第三Sの残余長が q≥4 の実対象で元full-tail freeが j+1 に届かないなら、M+L+q+v≤15。元Intp、padded BlockWord、zero/fullpositive、真正四A-runの実P2を保つ。紙上のactual接続は未Lean・人間レビュー未。

## 同じ実履歴での会計

第三Sの対象残余を q、第三A長を U、最後S/A長を v/T、最初の二A長の和を W=M+L、R=j+1、p=q+v と置く。実対象窓 S^q A^U S^v A^T S^j のmassとareaから T+U=R+p、p²=R²+2Uv。U,v≥1 より p>R。実head供給 EH≤10、最後rayの実供給 E≤7、実free F≤R−1 と A=W+U+T=EH+E+F を結ぶと W+p≤16。実head freeを r とすると T+r≤F+E から p+r≤U+6。すべて元の実窓の数え上げ。

W+p=16 と仮定すると EH=10、E=7、F=j。E≤T なので T≥7 と r≤F。r≤3 なら既存のr3 countで EH≤r+1 となり矛盾。よって r=W+U−10≥4。W≥2 と q≥4、v≥1 より 5≤p≤14。qや選択窓を全旧履歴の長さと同一視しない。

## 二つの局所供給元

最後rayの各時計は、旧履歴の供給一件、先行する五つの定符号区間の局所供給各一件、最後のA/S対の時計2の和集合で覆われる。旧履歴は実tailに少なくとも三つのSがあるので、BlockWordのold-ray上限一件を適用できる。元基点での計数とこの和集合は実A-run countの等式で対応する。よって実供給が7件なら第二Aと第三Sの各源が区間内に存在する。一件でも欠ければ和集合は高々6件。源ごとの時計は同じと仮定しない。

第三S源の残余を k とすると E-587 から 1≤k<q と (q−k)(q+k+2v)=R²−1。ここで j≥4 は上の r≥4 と F=j から従う。b=k+v と置くと R²+b²=p²+1、2≤R,b<p。第二A源は a≤L≤W−1 の深さを持つ。

- p=14 は同じ第三S源に対する E-589 が排除。
- p=12,13 は W≤4、L≤3、s+v≥q+v≥12。E-589 の第二A・第三Sのkey衝突で排除。具体的に x=s+v−a≥9 に対し b²=x²−a² が (x−1)² と x² の間に入る。
- p=5,6,9,10,11 は R²+b²=p²+1 に解がない。大きい側の値だけを調べると、順に 4 / 5 / 7,8 / 8,9 / 8,9,10。相方の平方は順に 10 / 12 / 33,18 / 37,20 / 58,41,22 でどれも平方数でない。
