## 現在の証拠と未解決事項

A は加算、S は減算、SS は隣接する二つの S の組を表す。SSS は SS を二つ含む。
P2 は新しい順の過去符号窓について mass=1、moment=0 が同時に成り立つ条件である。
low-SS は窓の SS 数が高々一つという意味で、周期全体の SS 数の制限ではない。
D は一周期内の S 位相集合、U は P2 供給を持つ加算位相の集合とする。

## 次の一単位の正確な問い

状態は **CONJECTURED、未着手**。この記録では新しい実験や Lean 実装は開始しない。

任意の正整数 p、周期 p の符号列 e:Int→Bool を取り、一周期の符号和が正とする。
L は 0 以上 p 未満の相異なる current-A 位相の有限集合で、各 b∈L に指定した
正の lag ℓ(b) が P2 と SS≤1 を満たす。L の窓の最小性は仮定しない。

v,w は L に属さない相異なる current-A 位相とし、それぞれの指定窓は P2、SS=2、
かつ正の真の P2 接頭辞を持たない。各窓の真の最古 S 位相を

```text
σ(x) = phase p (x - oldestOffset (past e x ℓ(x)))
```

とする。σ(v)=σ(w) のとき、次が成立するかを判定する。

```text
B = L ∪ {v,w}
N(B) = B の指定窓内に現れる S 位相の集合
|N(B)| ≥ |L| + 2 = |B|
```

周期・窓長・位相数の固定上限、一般 Hall 条件、所有者写像、NoSAAS、
実軌道への到達可能性は仮定しない。同一の周期符号列上の実際の窓を使う。
これは二窓の場合の局所 Hall 不等式であり、一般容量を仮定する言い換えではない。

## 既存結果から導ける補助整理

以下は **PROVED-PAPER、既存定理からの帰結で未 Lean 化**として区別する。
独立した新しい構造発見として数えず、次の実装に必要な範囲で統合する。

1. **一つの SS=2 窓を追加した非厳密容量。**
   E-368 の `lowSS_endpoint_image` は、L の各窓の内側にある相異なる S 位相を
   |L| 個与える。`oldest_phase_ne_lowSS_endpoint` により σ(v) はその像に含まれず、
   `donor_oldest_is_S` と oldestOffset の範囲から σ(v)∈N({v}) である。
   全て N(L∪{v}) に入るため、|N(L∪{v})|≥|L|+1 が従う。
   |L|+2 という厳密余剰までは導いていない。
2. **最古 S が異なる二窓。**
   σ(v)≠σ(w) なら、上と同じ像の外に相異なる S 位相を二つ加えて
   |N(L∪{v,w})|≥|L|+2 を得る。未知部分は σ(v)=σ(w) の場合である。
3. **同じ最古 S を持つ SS=2 群は高々二つ。**
   E-363 `minimal_p2_terminal_bound` と SS=2 より、最古 S より古い末尾 A の長さ
   t は 0 または 1。窓全体の古い端点位相は σ(x)−t（mod p）である。
   同じ σ と同じ t を持つ二窓は full endpoint 位相が等しいので、
   `TwoSSPeriodicSupply.two_SS_endpoint_mod_injective` により current 位相も等しい。
   位相は相異なるため、各型は高々一つで、衝突する二窓は t=0 と t=1 の組となる。

依存先は [SS2LowSSTight](../Recaman/SS2LowSSTight.lean)、
[TerminalASSBound](../Recaman/TerminalASSBound.lean)、
[TwoSSPeriodicSupply](../Recaman/TwoSSPeriodicSupply.lean)。
E-131 は窓全体の端点が共通の場合を扱う。最古 S の一致だけで適用してはいけない。

## 反証と受入条件

実行開始前に [仮説カード](HYPOTHESIS_CARD_TEMPLATE.md) を作り、探索範囲、
discovery と holdout、ソース revision、コマンドと出力保存先を固定する。
過去に使用した範囲は再利用と明記し、未使用の holdout と呼ばない。

必須の検査例は E-133 の周期16の衝突である。
`AAASSSASASA` と `SASASAASAAAASSSASAS` の最古 S が重なるという
[記録](HYPOTHESIS_CARD_2026-09-10_TWO_SS_OLDEST_S.md)を再現し、
正符号和を含めた今回の全前提と突き合わせる。空の L、末尾 A 長 0/1、
周期境界を跨ぐ窓、lag が p 以上の窓、非最小 low-SS 窓も検査する。

最初の反証・紙上検討を **実行開始から60〜90分**で区切る。受入は、
全 p・全 lag に通用する構造補題と完全な証明経路、または今回の前提を全て満たす
明示的反例とする。証明経路が立った場合にだけ Lean 化と別セッションの意味監査へ進む。

追加 S を donor 二窓の内部だけに限定する方法は十分条件の候補に留める。
局所 Hall の証明では low-SS 側の割当の組み替えも許す。
固定割当が壊れた場合と、近傍個数の不等式そのものが壊れた場合を区別する。

構造補題に届かなければ、不足する一つの補題と失敗した方法を記録して STOPPED とする。
窓長の列挙上限を伸ばすだけの継続、反証された最古 S 単射の再主張、
定数幅の所有者距離への修理、新しい未証明 Prop による包装は行わない。
局所 Hall の反例はその割当経路を止める根拠であり、それだけで E-070 や全域性を反証しない。

## その先の段階

1. **複数の SS=2 衝突群の同時配分。** 二窓の成功だけでは、別の群が同じ追加 S を
   利用する可能性は消えない。固定した実符号語上で、全ての部分集合に通用する配分・
   個数評価が必要である。
2. **SS≥3 の窓。** 最古 S の供出則には E-345 の反例がある。別の選択原理または
   共同容量を設計する。SS=2 の結果をそのまま延長しない。
3. **一般容量 E-070。** Hall を仮定した削除後の Hall 保存から、無条件 Hall を
   得たことにはしない。帰納を使う場合は、その仮定をどう供給するかを明示する。
   候補グラフの S 頂点を削除する操作と、符号語自体を変える操作を区別する。
4. **未供給位相と非周期性。** E-070 が証明できれば、正符号和による |A|>|D| と
   合わせて E-067 が従う。E-065 と合成すると、有限履歴からの実更新の最終的な
   符号周期性を排除できる。E-067 の直接証明が得られた場合もこの接続を使える。
5. **全域性への判断ゲート。** 非周期性だけでは永久欠損を排除できない。
   周期を仮定しない実履歴の供給、境界を越える履歴、blocker 再利用を扱い、
   [永久欠損の A/B 残余](PROOF_MAP.md#2026-09-01-missing-tail-residual-kernel)を
   矛盾させる新しい数学的入力が必要である。入力が得られるまで、既存 oracle の
   統合だけで全域性へ到達すると見込まない。

当面の到達目標は周期供給理論の前進である。全域性の完成時期や進捗率は見積もらない。
新しい結果が出た時点で、証拠の水準を保ったままこの順番を再評価する。
