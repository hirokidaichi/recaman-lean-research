## Exact statement

記法と完成設定Dは[配分文書の仮定台帳](RESEARCH_ALLOCATION_2026-10-21.md)を用いる。

**C2（消費側の目標）**: 全てのDと `q0≤b<c` について、`Endable_p(b)`、`τ_p(b)<q0`、
`∃t, k1<t<q0 ∧ P2(t,b)` なら、全ての `q0≤u<b` で `σ(u)=A`。
すなわち、このはみ出しの前の `[q0,b)` にはSがない。

**C2′ v1（強い補助候補）**: 任意の有限語と `p<q0≤b<k` で、次を仮定する。

- `p≤u≤q0` で `d_p(u)≥0`、`d_p(q0)=1`、k1はq0より前の最後の零点。
- `q0≤u≤b+1` で `d_p(u)≥1`、`a_p(q0,b+1)≤1`、`σ(b)=A`。

このとき全ての `k1<t<q0` に対して `P2(t,b) → b−t=3`。
完成条件と「局所窓がない」はC2′には課さない。Dの `b<c` から上の接頭辞条件を供給できるかも監査する。
長さ3のP2語は前向きにSAA（Leanの `past` は逆向きAAS）。`t<q0≤b` なので `[q0,b)` は
末尾のAAの部分であり、C2′からC2へ進むにはこの符号分類と仮定供給を両方確認する。
