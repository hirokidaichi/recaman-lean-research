## Q2 の結果（2026-10-03 午前、探索的。紙上の主張を親が検算したかどうかは各項に明記。Lean 化したものは E 番号付き）

記法：F(t) = Σ_{c<t} sign σ(c)、メンバー b の水準 h_b = F(b) − 1（窓の始点 t_b で F(t_b) = h_b）、S clock c の「上端」F(c)（下り段 c → c+1 の上の高さ）。

1. **窓の S 水準恒等式（E-362、PROVED-LEAN）**：任意の P2 窓（lag L = 4m+3、最小性不要）で Σ_{S c ∈ W_b} (F(c) − h_b) = m。
   系：全 S が水準以下にある P2 窓は AAS だけ、lag ≥ 7 の窓は水準より真に上の S を持つ。どの P2 窓も水準ちょうどの S（最初の h_b → h_b − 1）を持つ。
2. **周期語の G1 の分解（紙上）**：緊密 B の持ち上げの窓の和集合 I は I + p = I なので、成分は全て有限か I = ℤ。
   I = ℤ なら N(B) は全 S phase、|B| = |D|、Hall から |U| ≤ |N(U)| ≤ |D| = |B| で U = B（E-070 の等号の場合。E-177 は等号語の窓が ssCount ≤ 1 と言うだけで lag は縛らない）。
   有限成分 J は、W_b ⊆ J なるメンバーと own の制限で line model の有限閉包になる（own(b) ∈ W_b ⊆ J、J 内の S の所有者の窓は J と交わるので J に含まれる）。
   従って **G1 ⟸ (有限閉包の G1) ∧ (等号の場合の G1)**。有限閉包では最新メンバー y+1（J = [x, y]）と最大値 K = max_{[x, y+1]} F という極値が使える。
   **計算（E-365）**：E-349 の census に「B の窓が全 phase を覆うか」を足すと、p = 6..26 の全緊密集合（約 1,030 万、p = 26 で 5,126,692）で 0。
   等号の場合（和集合 = ℤ）は census の範囲では起きない（`experiments/issue73_20261003/tight_cover_census.cpp`）。
3. **補題 T（UP-FREE の下、全 lag、紙上）**：UP-FREE「各メンバーは F(own b) ≤ h_b」を仮定する。有限閉包の成分 J = [x, y] について
   (a) F < K on [x, y]、F(y+1) = K、上端 K の S はない。(b) 最新メンバー y+1 の窓は [y−2, y] の AAS で y−2 を所有（上端 K−1 の S は y−2 だけ）。
   (c) J ≠ [y−2, y] なら y はメンバーでない（y の窓の面積条件が 1 項 −1・2 項 (−1,−1)・3 項以上 ≤ −3 のどれでも −2 にならない）、上端 K−2 の S はなく、
   σ(y−3) = σ(y−4) = A、F ≤ K−3 on [x, y−4]、x ≤ y−4。(d) その下は w1 三つ組：y−1 の窓は [y−8, y−2] = SAAAASS（K−3 より下の
   excursion の面積は {1, 4, 7, 9, …}、上端 K−3 の S の所有者候補は y−1 と y−3 だけなので excursion は 1 本で面積 4 = (−1, −2, −1)）で最古 S y−8 を所有、
   y−3 は P2 窓を持たない、y−7 の所有者は y−4 だけで、見えている接頭辞 AAS から最小窓は AAS（最小性を使うのはここだけ）、F ≤ K−4 on [x, y−9]。
   **従って UP-FREE の下では、有限閉包の各成分の上端は孤立 AAS か w1 三つ組で終わる。**
   (e) 剥離はここで止まる：x < y−8 なら y−9/y−8 をまたぐ窓は y−5（水準 K−5）か y−6 の窓だけで、W_{y−5} は lag 11 の 2 語
   （ASSAAAASSAS／ASSAAASAASS）に絞られ、長い窓が古い側へ伸びる「階段」になる。lag 一様な不変量は未発見。
4. **計算（サブエージェント `lsearch.py`、親は lag 11 のノード数が参照と一致することのみ確認）**：E-356 探索に制約を足した場合の最大ノード数

   UP-FREE の逆向き（F(own b) ≥ h_b）はほとんど枝を刈らない。**Claim N（有限閉包の最新メンバーは AAS、u > 0 の所有者を禁止した探索）**は
   lag ≤ 19 の全語で成立し（所有者 ≤ 19）、長い v ほど木が小さい（lag 19 で最大 10 ノード）。UP-FREE の下では Claim N は補題 T(b) そのもの。
   最小窓の代わりに任意の P2 窓を許すと lag 11 でも閉包 0（490 ノード、全数）、lag 15 は memberCap 16 で 21 枝が cap（未決）。

   lag 23 では 17,880/18,556 語が根で排除される（v の S のうち古い側に整合する所有者を持たないものが 2 個以上）。

6. **TOP ⇒ Claim N（UP-FREE 不要、親の紙上議論＋E-362）**：TOP「有限閉包の成分 J = [x, y] で F(y+1) > F(c)（c ∈ [x, y]）＝歩みの最大値は最新メンバー
   y+1 でだけ達成される」を仮定すると、最新窓の全 clock で F(c) ≤ F(y+1) − 1 = h_{y+1}、つまり全 S の高さ ≤ 0 なので

   #S[z, y] ≤ #M[z+1, y+1]（own⁻¹ は [z, y] の S を b − 1 ≥ own(b) ≥ z なるメンバー b へ単射に送る）。歩みで書くと

9. **局所障害の角度（サブエージェント local-angle）**：(a) **命題 V**（証明済み、単純）：v の有界な部分だけを固定し、外の所有者を「u > s、u − s ≤ Λ、相異なる」
   以外自由にする遅延緩和は、Λ ≥ 直径 + S 数で必ず解を持つ（各 S を右端の外の新しい clock に所有させる）。**有界領域だけの議論は不可能**で、
   領域外の所有者の実際の窓を使う必要がある。(b) 実在の所有者窓を課す緩和では、v の 4 bit（例 `SASS`）だけで排除できる語が多い（lag 15 で 82/155）が、
   証明書は Λ とともに爆発し（`SASS@4`：Λ = 7/11/15/19 で 3/39/11,932/705,349 ノード、探索 span は約 5Λ）、Λ = 11 で排除できたパターンが Λ = 15 で
   排除できなくなる例もある。(c) **欠陥 1 の構成（親が独立に検算）**：clock −8..17 のビット `ASASASSSAAAASAAASSAAAASAAA` 上のメンバー
   3: AAASSSASASA（lag 11）、10: SSAAASAAAASSSAS（lag 15）、w1 三つ組 {2, 5, 7}・{12, 15, 17} の 8 個は、窓が全てビットから再計算した最小 P2 窓と一致し、
   N = {−7, −5, −3, −2, −1, 4, 8, 9, 14}（9 個）、最大マッチング 8 で未所有は −7 だけ。**長いメンバーを含む構成が 1 S の欠陥まで閉じうる**＝
   G1-strong（|N(B)| ≥ |B| + 1）の +1 は鋭く、排除は大域的な数え上げで決まる。(d) **S-prefix 補題**（紙上証明・計算確認 L ≤ 19）：最初の m 文字が S の
