## 正確な対象

元カードは、任意の整数符号語e、周期p>0、周期性、nodup・p未満のcurrent-A位相のBについて、
各 `lag b<=11` の全窓がP2で、mがその最短の正P2接頭辞であるとき、
`|N_lag(B)|=|B|` なら `N_m(B)=N_lag(B)` と問う。donorはこの等式命題の仮定にない。

Leanの逐語signatureは次のとおり。元カードよりもfull-window P2とmの最小性が少ない。

```lean
theorem tight_neighborhood_eq_of_p2_prefix (e : Int → Bool) (p : Nat) (hp : 0 < p)
    (hper : ∀ x : Int, e (x + p) = e x)
    (B : List Nat) (m lag : Nat → Nat) (hBn : B.Nodup)
    (hBp : ∀ b ∈ B, b < p) (hBA : ∀ b ∈ B, e (b : Int) = true)
    (hle : ∀ b ∈ B, m b ≤ lag b) (hbound : ∀ b ∈ B, lag b ≤ 11)
    (hP : ∀ b ∈ B, P2 (past e (b : Int) (m b)))
    (htight : (neighborhood e p B lag).length = B.length) :
    neighborhood e p B m = neighborhood e p B lag := by
```

`P2` はmass1/moment0、pastはnewest-first。neighborhoodはrange pの実際のS位相を
窓の被覆条件でfilterしたリストであり、自由な集合ではない。
`exists_minimal_p2_prefix` と `take_past` により元カードの前提から上の前提が得られる。
逆に、上の前提しか満たさない例を元カードのstrict subcaseの実例にしてはならない。
