## 3. 計画（順序・受入条件・停止条件）

各項目は 1 カード・1 モジュール・1 commit、statement audit 必須。「Grand／Universal」を名に持たない。

### P1. 対象の再定義（1 unit、Lean）
- `oldestSubtractionOffset e u d`（窓内の最大 offset の S）を定義し、`endpointPhase` との関係（d4/d5/d7 では一致、d1/d2/d3/d6 では offset 10）を
  7 語上の `decide` で固定。E-230/E-231 を「d4/d5/d7 型では従来通り、d1/d2/d3/d6 型では offset 10」に再定式化できるかを確認する。
- 受入：E-345 の census と同じ最古 S が Lean で得られる。停止：既存 p ≤ 10 証明が d1 型で再現できなければ、p ≤ 10 の実勢を「d4/d5/d7 型のみ」と記録して先へ進む。

### P2. G1 の証明（本丸、2〜4 unit、紙上 → Lean）
- 命題：Hall が U 全体で成り立つ正符号和周期語で、ss=2 donor u0 を避ける緊密部分集合 B のメンバーは全て lag ∈ {3,7}。
- 手掛かり：lag ≥ 11 の最小窓は ≥ 5 個の S を持ち、緊密性は他メンバーが ≥ 4 個を共有することを要求する。lag-3 の S は各メンバーで
  互いに異なる（端点が異なる）ので、共有は lag-7 窓（S が 3 個）か長い窓同士でしか起きない。E-266（互いに素な近傍のサイズ下界）と
  E-267（singleton 分解）を数え上げの骨にする。まず紙上で「lag-11 メンバーを含む緊密 B は存在しない」を書き切り、反証は probe で試す。
- 受入：紙上証明が p に依存しない。停止：p ≤ 31 の網羅で lag ≥ 11 のメンバーを持つ緊密回避 B が出たら、G1 を「lag ≤ 11」に弱めて再設定。

### P3. G2 の lag-7 側（1〜2 unit、Lean）
- E-348 の 3 配置（w1、u = s*+1）で、被覆窓の他の 2 phase は s*−5, s*−6。w1 は必ず lag-3 の兄弟 u−3（phase u−6 = s*−5 を被覆）を伴う。
  緊密 B が u を含むとき N(B) ⊇ {s*, s*−5, s*−6} と他メンバーの phase の数え上げが |B| に収まらないことを示す。
- 受入：E-348 と E-267 だけから導ける。停止：p ≤ 26 の census が示す通り反例はないので、証明が 2 unit で閉じなければ紙上に落として次へ。

### P4. Gate T6（ss=2 donor、一般 p）の組み立て（1 unit）
- G1 + G2 + 既存の「u0 を含む部分集合は生存」「slack 部分集合は生存」を合成。donor の lag が 11 でない ss=2 窓（15, 19, …）は
  E-348 の分類を lag ごとに繰り返す必要がある（census では全 lag で例外 0）。まず lag 11 で閉じ、他の lag は COMPUTED のまま置く。

### P5. Gate T6 から E-070 へ（2 unit、紙上 → Lean）
- 09-11 の T3/T6 論理：高 SS 窓が 1 つでもあれば `|U| ≤ |D| − 1`。各高 SS 窓の供出を順に削除して低 SS クラス（E-128）へ還元する帰納法。
  E-318 はこれを恒真式で偽装していた。実際の帰納法は「削除後も残りの窓が最小 P2 窓のまま」「削除した S が他の窓の唯一の供給でない」を要する。
  ssCount ≥ 3 donor は最古 S では失敗する（E-345）ので、供出則を「Hall を保つ何らかの S」に一般化した形で帰納する。
- 受入：E-070 を実符号語 e と周期 p を binder に持ち p 上限なしで述べた定理。昇格は広木さんの承認（PROTECTED_CLAIMS）。

### P6. E-067 と非周期性（1 unit）
- E-070 から E-067 は算術（`signSum > 0 ⇒ |D| < |A|`、E-320 の `positive_sum_subtraction_lt_addition`）。E-065 と合わせて
  「標準軌道の符号列は最終周期的でない」が無条件になる（E-320 の low-SS 版を全 lag に拡張）。

### P7. 全射性との関係（判断項目、証明項目ではない）
- P1〜P6 が全部閉じても得られるのは「符号列の非周期性」であり、全射性・非全射性そのものではない。全射性側の枝
  （landing floor T4、corridor、permanent-above tail）は 09-03〜09-07 に STOPPED、09-15 の「枝の排除」は空だった。
  見立ては非全射側（Chaffin の 852655 が 10^612 項まで欠損）。P6 の後に、E-025 の二分定理 D（`a n ≤ n+2` が無限回 or 欠損密度 ≥ 1/4）と
  非周期性を結ぶ新しい不変量が書けるかを 1 unit だけ試し、書けなければ研究の主目標を「周期供給の理論の完成（E-067/E-070）」と再宣言する。

## 4. 見通し（正直に）

- **G1/G2/Gate T6（ss=2、lag 11）**：計算証拠は p ≤ 26 で例外 0 と強い。局所補題は揃いつつある（E-267/276/311/348）。
  数え上げ論法が書ければ Lean 化は decide 中心で軽い。**中程度の難度、2〜3 週間の unit 積み上げ**が妥当な見積もり。
- **E-070 全体**：ssCount ≥ 3 donor の供出則が最古 S ではないため、帰納法の設計が本質的に未完。**高難度**。E-180（線形衝突会計の反証）
  が示す通り、単純な課金は死んでいる。
- **全射性**：本計画の射程外。周期供給理論は「非周期性」までで、そこから先は新しい不変量が要る。
- **リスク**：生成ループが再び「合成定理」で見かけの進捗を作ること。ハーネス（G1〜G5、pin、速度制限）で機械的に止めるが、
  G3 は `have` 入りの連言合成を通すので、**statement audit の人間レビュー**（広木さん）が最後の砦。
