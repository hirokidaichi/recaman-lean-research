# Geometric kernel certificate

GeometricKernel.lean.txt is the exact source accepted in H37 under Lean -j1 -M512. Its source SHA256 is recorded in H37-result.json and the content-addressed frozen copy. Copy this text source to a temporary .lean path and run lake env lean -j1 -M512 with that path to reproduce.

The certificate checks only the finite geometric coefficient. E675 remains PROVED-PAPER. H38/R attempted the complete original-cN transport and was STOPPED after one repair. Its source is quarantined under stopped and is absent from Recaman.lean and Recaman/Audit.lean.
