# C2仕様監査: 既知入力の再計算（実行前固定）

- 固定日: 2026-10-22、実行前に本ファイルを保存する。
- カード: H-20261021-03、cycle R-20261021-01。
- 問い: 既知の弱化反例と三つ組境界例について、窓・d・a・k1を直接再計算すると、C2′ v1のどの仮定を満たし、どれを外すか。
- 予算変更: 初回CPU追加0から、本監査の単発実行のみCPU上限5秒・経過上限10秒へ変更する。
  C2活用枠内の監査準備から費用を割り当て、当日の8:00や100分cycleの上限を増やさない。
- 入力（全件固定、追加探索なし）:
  1. `SAAA`（長さ3の窓を持つ基本語、q0=1）
  2. `SSAAAASA|AA`（q0は区切り位置、終端d=0の既知三つ組）
  3. `SSSAAAASAAA|SSSSAAAA`（a_y≤2への弱化による既知の長い窓）
- 計算法: 全t<bについて、直接の符号和1と重み付き和0でP2を判定する。
  旧probeのF/Gによる二式、長さを4ずつ飛ばす走査も同じ全入力で別に照合する。
  EndableはA clockを一回だけ数え、全d(u)、全a(q0,u)、候補窓を出力する。
- discovery / holdout: 新しい予想の探索ではなく既知入力の再監査なので、いずれも該当なし。
  既知入力を独立holdoutや未使用の数学的検査範囲とは呼ばない。乱数・全語列挙・上限延長は行わない。
- 合格: 独立な二式と走査が一致し、陰性対照の具体的な違反箇所と全仮定の真偽が保存される。
- 停止: 実装差・既知反例の再現失敗・上限超過で停止し、数学的反証と実装不備を混同しない。修理せず原因を記録する。
- 証拠: exact有限再計算だけをCOMPUTEDとする。C2/C2′/Hの無制限の主張は昇格させない。
- 保存: audit.py、result.json、source revisionとdirty diff・使用source hashes、command、実行時刻、正確なstdout、SHA256SUMS。
