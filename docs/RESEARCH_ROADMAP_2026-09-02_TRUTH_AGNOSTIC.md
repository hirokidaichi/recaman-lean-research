# 研究ロードマップ（2026-09-02）: 全射性の真偽を問わない証明計画

作成: 2026-09-02 午前  
前提: 「全射性が偽であっても構わない。どちらでもよいので証明を進める」という方針転換を受ける。

## 0. 方針転換が変えること

これまでの計画は「欠損値が存在すると仮定して矛盾を導く」枠組みだったため、
「欠損値が無限個ある」「欠損値の密度が正である」のような結論は「矛盾ではない」として
棚上げされてきた（`E-004`の判定「構造的代償。矛盾ではない」がその例）。真偽を問わない立場では、
これらがそのまま**主定理**になる。counting・density・凍結補題は禁じ手ではなく主武器になる。

同時に、真偽の判定そのものは計算では決着しない。この文書は
(1) 今日の計測で得た軌道の実像、(2) それに基づく真偽の見立て、(3) どちらに転んでも
定理として残る成果の順序、(4) 計算基盤と判定基準、を固定する。

## 1. 軌道の実像（`near_diagonal_rate_probe`、canonical 3e9、`COMPUTED`）

記法: 時刻 `n` の値 `a n`、高さ `h n = a n − n`、cone余剰 `e n = a n − 2n − 1`、
candidate `c n = a n − (n+1)`。interior は `a n ≤ 2n+1`。

| 量 | 1e3〜1e7 の各decade | [1e8,1e9) | [1e9,3e9) |
|---|---|---|---|
| sub-diagonal `a n < n` の割合 | 28.5% | 28.6% | 28.6% |
| interior の割合 | 64〜66% | 64.6% | 64.9% |
| 時刻 `n` で未訪問の値 ≤ n の割合 | 44〜54% | 54.8% (at 1e8) | 51.1% (at 1e9) |
| 高さ `1 ≤ h ≤ 1356` の時刻数 | 608〜1322 /decade | 47 | 0 |
| 高さ `1357 ≤ h ≤ 4095` の時刻数 | 913〜2427 /decade | 913 | 1123（部分） |
| decade内の最小正高さ | 1〜2 | 1217 (@302,890,399) | 2405 (@2,789,149,735) |

読み取り。

1. 軌道は対角線を恒常的に横断する（sub-diagonal 28.6%で安定）。従って A枝（eventual-high
   corridor: `a n > n + target + 1` が永久に成立）は経験的に全ての target で偽であり、
   `E-021`〜`E-023` の supply 系解析が扱っていた無限 corridor は実在しない対象である。
2. 値 `t` が遅れて着地するのは、interior 時刻 `n` の高さが `h n = t + 1` で `t` が未訪問のとき
   だけである（`a (n+1) = a n − (n+1) = t`）。従って「小さな高さ」の頻度が全射性を決める。
3. 小さな高さは孤立して現れない。**descending chain**（既存B枝の comb と同じ機構）で現れる：
   高さ `h` の interior 時刻で candidate `h−1` が既訪問なら強制加算で余剰 `h−2` の exterior 時刻へ、
   その candidate `n+h−1` が未訪問なら着地して高さ `h−3` へ戻る。2時刻ごとに高さが3減り、
   帯 `[n, n+h]` の値を連続して埋める。[1e8,1e9) の47件は高さ 1355→1217 の1本の chain
   （46段）であり、機構が exact に確認された。
4. chain の小さな candidate は `h−1, h−4, h−7, …` と mod 3 の1剰余類しか走らない。
   mex 1355 を着地させるには高さが `≡ 0 (mod 3)` の chain が高さ 1356 を通過する必要があり、
   上の chain（高さ `≡ 2`）では原理的に不可能だった。これが「mex が 1e6〜3e9 で凍結」の正体である。
5. 高さ ≤ 1356 への chain 侵入は 1e7 まで decade あたり数本、[1e8,1e9) で1本、[1e9,3e9) で0本。
   減衰しているように見えるが、侵入は Poisson 的に稀な事象で、3e9 では `c/n` 則
   （decade あたり一定）と「減衰」を区別できない。

## 2. 真偽の見立て

- 値 `t` が遅れて埋まる期待回数は「高さ帯 `[1, t+1]` への chain 侵入率 × 剰余類と帯の未訪問run
  の条件付き確率」の総和である。侵入率が `c/n` なら対数発散して全射性、`n^{−1−ε}` なら収束して
  非全射になる。既知の計算（Chaffin: 852655 が 10^230 項まで未出現、と記憶している）は
  `c/n` 則のもとでは期待回数が数十〜数百になるため、**定数 c が極めて小さいか、侵入率が減衰する**
  ことを示唆する。後者なら非全射である。
- しかし 1355 が 3e9 で未出現のまま 10^15 までに出現する（852655 が最小欠損という事実の帰結）
  なら、剰余 `≡ 0 (mod 3)` の chain が高さ 1356 を通過する事象が (3e9, 10^15] に少なくとも
  1回ある。これは侵入率が急減衰していない証拠でもある。
- 結論: 現時点で真偽は決められない。ただし**両方向の証明が同じ対象（chain の侵入と生存）に
  帰着する**ことは確定した。ロードマップはこの対象を中心に組む。

## 3. 定理ロードマップ（優先順）

### T1. 二分定理 D（`PROVED-LEAN`: `MissingDensityDichotomy`、2026-09-02 完了）

**定理 D.** 次のいずれかが成り立つ。
(I) 無限個の `n` で `a n ≤ n + 2`（candidate ≤ 1）。
(II) 一度も訪問されない整数の集合は下密度 ≥ 1/4 を持つ。

証明。(I) が偽なら `N` があって `n ≥ N` で `a n ≥ n + 3`。
(a) 孤立補題: `n ≥ N` が interior（`a n ≤ 2n+1`）なら `n+1` は exterior。減算なら
`a (n+1) = a n − (n+1) ≤ n < n + 4` で法則に反するから加算であり、
`a (n+1) = a n + n + 1 ≥ 2n + 4 > 2(n+1) + 1`。
(b) 凍結補題: `m ≥ N`、`u ≤ m + 2` が時刻 `m` までに未訪問なら永久に未訪問。以後の加算出力は
`≥ 2j + 2 > m + 2`、減算着地は `a j ≥ j + 3 ≥ m + 4`。
(c) 計数: 窓 `[0, m+2]` は `m+3` 個。時刻 `m` までの訪問値は `a 0 … a m` の高々 `m+1` 個で、
`(m/2, m]` の exterior 時刻は `a n ≥ 2n + 2 > m + 2` だから窓に寄与しない。(a) より `m ≥ 2N` で
`(m/2, m]` の少なくとも半分は exterior。よって窓内の未訪問は
`(m+3) − (m+1) + ⌊⌈m/2⌉/2⌋ − 1 ≥ m/4 + 1`。(b) よりそれらは全て永久欠損。□

系 D1. 任意の `target ≥ 1` について、A枝 `EventualHighCandidateTail target` は (II) を含意する。
系 D2. (I)（sub-diagonal 着地の再発だけで十分）は全ての target について A枝を否定する。

意味: A枝は「欠損値が密度 1/4 以上」という強い構造を伴わなければ起こり得ない。データは (I) 側
（28.6%）であり、A枝は経験的に消える。残る非全射機構は B枝＝chain だけである。
Lean 化は完了した（`missing_density_dichotomy`、`missing_window_of_law`、
`EventualHighCandidateTail.missing_density`、`not_eventualHigh_of_recurrent_low`）。
形式化では計数の結論が `m ≤ 4·|missing|` まで締まり、凍結は法則から直接出るため
加減算の場合分けは不要だった。

### T2. chain 補題（exact、Lean 化）

高さ `h ≥ 4` の interior 時刻 `n` で candidate `h − 1` が既訪問なら、
`a (n+1) = 2n + h + 1`、`c (n+1) = n + h − 1`。この値が未訪問なら `a (n+2) = n + h − 1` で高さ `h − 3`。
終了は次の2種に限る: (α) 帯の値 `n + h − 1 − k` が既訪問 → 加算で余剰が `≈ n` に跳ぶ（上方脱出）、
(β) 小さな candidate `h − 1 − 3k` が未訪問 → その値の遅延着地。(β) の後 chain は高さを1ずらして
続行し、剰余類が1つ動く。連続する未訪問値があれば `v, v−1, v−2, …` を続けて埋める（既知の comb）。
既存の `HistoryTerminatedComb` 系は同じ対象を target 相対で扱っているので、target を外した形に
一般化して剰余類の主張を加える。予定 2 ラウンド。

### T3. 遅延着地の特徴づけ（Lean 化、小）

「`t < j` で `a j = t`」⟺「時刻 `j−1` は interior で高さ `t+1`、かつ `t` は時刻 `j−1` まで未訪問」。
さらに T2 と合わせ、「小さな高さは chain の内部か chain の侵入時刻でしか現れない」を
exact に述べる。非全射性の判定条件を次の形に固定する:

```text
t が永久欠損 ⟺ 高さ t+1 を、t が未訪問のまま通過する時刻が存在しない
            ⟸ 高さ t+1 に達する chain が、剰余類と帯の未訪問 run の条件を満たして
               現れることが二度とない
```

### T4. 本丸: chain 侵入・生存の定量定理（真偽を決める）

両方向の証明はここに帰着する。

- 非全射方向: ある `K` について、高さ帯 `[1, K]` への chain 侵入が有限回で止まることを示す。
  侵入は「余剰 `≈ n` の exterior 時刻から candidate `≈ 2n` が未訪問で着地する」事象なので、
  値 `≈ 2n` の帯の未訪問密度と、着地後の帯 `[n, n+K]` の未訪問 run の長さを同時に制御する
  必要がある。手掛かりは「chain 自身が帯を連続して埋める」自己消費性である。
- 全射方向: 全ての `t` について、剰余 `≡ t+1 (mod 3)` の chain が高さ `t+1` まで生存して
  到達することを示す。到達には `(H − t)/3` 段の生存が要り、各段は帯の値の未訪問性を要求する。
  帯 `[n, n+10^5]` は 3e9 まで 65〜100% 未訪問なので生存自体は容易だが、
  侵入率の `c/n` 則を証明しなければならない。

どちらも「履歴の未訪問密度」を大域的に制御する invariant を要求する。これは従来の壁と同じだが、
対象が仮想 corridor ではなく実軌道の計測可能な統計になった点が異なる。T4 は
hypothesis card 化して、まず §4 の計算基盤で `c/n` 則か減衰かを判定する。

### T5. 非全射なら欠損値は無限個か（構造定理、両方向で意味がある）

「`t` が永久欠損なら、`t` より大きい永久欠損値が無限個ある」。A枝側は定理 D で密度 1/4 が
出る。B枝側（chain 機構）では、`t` を飛び越す chain が同じ剰余類の値を系統的に飛び越す
（剰余 mod 3 の構造）ことから、`t` と同じ剰余類の値が繰り返し欠損する形が予想される。
これは T2 の直接の系として紙上で試す価値がある。

## 4. 計算基盤（T4 の判定に必須）

1. **run-length 履歴シミュレータ**: 訪問集合を区間列で持ち（Chaffin 方式）、1e12〜1e15 まで
   走らせる。記録するのは (i) 高さ帯 `[1, K]`（`K = 2^10 … 2^20`）への chain 侵入時刻と
   侵入高さ・剰余類、(ii) 各 chain の破断段数と破断理由 (α)/(β)、(iii) 帯 `[n, n+K]` の
   未訪問 run 長、(iv) 値 `≈ 2n` の未訪問密度。Chaffin の 852655 と、1355 の初出時刻で検証する。
2. **侵入率の判定**: decade ごとの侵入本数が一定（`c/n`）か減衰かを、Poisson の信頼区間つきで
   報告する。1355 の初出時刻（(3e9, 10^15] のどこか）は `≡ 0 (mod 3)` 侵入の実例になる。
3. **generalized orbit での再現**: T2/T3 の主張と剰余類の障害を、`generalized_orbit_supply_probe`
   の母集団（20,001 本）で falsify する。

## 5. 判定基準と停止条件

- T1〜T3 は Lean の `#print axioms` を合格基準とし、既存の `check.sh` と registry 同期で閉じる。
- T4 は hypothesis card で quantifier を凍結する。侵入率が `n^{−1−ε}` で減衰するなら
  「非全射」の紙上証明を目標に切り替え、`c/n` なら「全射」の紙上証明を目標にする。
  どちらの証明も「帯の未訪問密度」の大域 invariant が見つからなければ `STOPPED` にする。
- 「有望そう」「さらに調べる」で閉じない（既存 protocol と同じ）。

## 6. 既存資産の扱い

- A枝の supply／burst／collision 系（`E-003`〜`E-023` の大半）は、定理 D により
  「密度 1/4 の欠損」を伴わなければ起こり得ない corridor の解析だった。retire し、
  D の系として一括で参照する。`E-021`（preload-free orbit の link no-go）は
  chain の生存問題の特殊形として T4 に吸収する。
- B枝の comb／blocker／reset 機構は T2 の chain 補題そのものである。target 相対の定式化を
  外して再利用する。
- `TailHall₃` 型の独立部分定理は、T1 の孤立補題と同じ技法で `liminf a n / n` の評価に
  つながる可能性がある。優先度は低い。

## 8. この文書が主張しないこと

- 定理 D は全射性の真偽を決めない。データは (I) 側であり、D は A枝を実質的に消すだけである。
