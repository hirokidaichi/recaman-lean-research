01 / VERDICT

何が進み、何を止めるのか

問題そのものは未解決だが、研究判断はかなり明確になった。直接枝を増やすフェーズから、欠けている因果情報を特定するフェーズへ移る。

研究上の結論

局所の符号列・合同類・ledger identity は、正準反例をかなり狭い座標へ押し込む。しかし、それだけでは permanent-above tail を排除できない。

したがって、Leanの定義や有限分類を増やすことは、現時点では証明進捗ではない。新しい数学が紙上で出るまで直接形式化を再開しない。

02 / EVIDENCE

証拠の台帳

「証明済み」「計算で支持」「no-go」「未証明候補」を混ぜない。ボタンで種類を絞り込める。

proved in Lean

正準 tail minimum は低商に入る

least missing target の最小tail minimumは q≤1、G≥−1、ledger corridorを同時に満たす。

2·subSum(t)+(target+2) ≤ upperTri(t)
upperTri(t) < 2·subSum(t)+2t
proved in Lean

canonical high branch は空

aₜ < t+target かつ q=0 ∨ (q=1 ∧ r<target)。前に有望視したhigh-blocker分岐は正準点では到達不能。

proved in Lean

単一 blocker の sharp C=3 payment

正のearlier occurrenceが後の増加を作ると、3-clock gapと正確なledger支払いが生じる。ただし一般tailの部分定理。

earlier+3 ≤ time
time+1 ≤ ΔsubSum+3
proved in Lean

low candidate は孤立する

永久上側tailでtarget未満のcandidateは既出なのでforced addition。その次はtarget omissionにより厳密にhighへ戻り、LLは不可能。

proved in Lean

terminal blocker は一回消費

fresh combの全low railはfirst occurrence。終端blocker bはfresh successor b+1に注入され、別の完了combへ再利用できない。

proved in Lean

各lowからfinite terminalを抽出

fresh landingからlow railの自然数下降へ強帰納し、有限maximal combを構成。その終端が必ずhistorical blockerになることまで証明。

proved in Lean

terminal normalをsemantic mount

historical terminal blockerをextended/refined/semantic domainへ搭載。later-entry-leftとpre-tail ceiling超resetはstrict progressになる。

proved in Lean

fresh interval はpairwise全順序

任意二つの時間順combで、later intervalはearlier blockerより下、またはearlier interval全体がlater blocker以下。値区間は交差しない。

20M remount audit

distinct root 851/860がanchor左へ戻る

未解決9件はtarget出現またはhorizon censor。待ち時間は最大653 episodeへ伸びるためuniform boundは偽で、非一様no-escapeが候補。

fresh-mass audit

no-escapeならfresh massは非有界

#waiting≤Q≤maxEntry−root、resolved時2Q≤clock gap。20M違反0。ただし最長待ちのhull密度は22.75%で単独矛盾にはならない。

Lean countermodel

macro条件だけではfinite basinを脱出しない

bⱼ=r+j, entryⱼ=r+j+1のright ladderはinterval order・one-use・unboundednessを満たし、一度もentry<rを起こさない。

clock audit

singleton ladderは5 clock空くが排除不能

terminal後の二加算とparityから次entryは5 clock以後。しかしsⱼ=6jが全clock条件を満たすため、必要なのはvisited-sensitive no-return。

Lean prefix counterexample

無条件fresh-entry no-returnは偽

target 4でentry 39が介在episode後にterminal blocker 39として戻る。immediate predecessorに限るgated形だけが20Mで0/2,655。

exact residual no-go

successor returnはreuseまたはavoidance

旧entryがhigh wordで再露出すればforced reuse balance、しなければ全区間avoidance。現行ledgerはどちらも排除せず、局所successor枝を停止。

20M successor audit

parity-or-mass hybridは2,655辺で違反0

δ odd ∨ q≤δ。entry returnがparity-compatibleになることはLean化したが、新規は4辺だけで共通機構なし。過適合寄りとして停止。

Lean seeded family

任意長のhigh forced corridor

target 1を欠くfinite historyをseedすると、任意長だけ実Basic.stepをhigh forced additionにできる。局所符号・ledger・parityからuniform boundは出ない。

2B canonical audit

upward reset 28/28はrecord・addition初出

ただしbirth candidateは19/28がepoch内生成、terminal fresh interval由来0/28。再利用最大1でも有限capacityにはならない。

seeded actual-orbit no-go

upward recordのsubtraction初出は局所的に可能

target 5でblocker 16→230のright-record resetを構成。230は326−96で初出し、addition-origin則がcanonical固有だと確定。

Lean exact kernel

missing tailを二つの残余へ完全分解

eventual-high candidate corridorまたはfixed finite rootの右側を走るunbounded terminal stream。有限pre-tail oracleから直接導出し、循環的なsemantic closureは使わない。

2B terminal-anchor audit

21,495 / 21,510 anchorsが後でstrict return

upward reset 28件中26件は次terminalで返済。残る2件はtarget 4が実際に出現してepoch終了。ただし一般waitは最大20,097でuniform boundはない。

macro no-go

短いancestry / stack traversalは偽

祖先鎖は最大60,651 hop、edge再利用7。interval移動はupwardで最大2,237本を飛び越え、局所stackではない。

gap flux no-go

record gapの半分以上が未訪問で残る

gap mass 17,820,564、20Mでも未訪問9,518,181。cut balanceは望遠和へ退化し、独立枝として停止。

sharp no-go

uniform exit margin は存在しない

5,779,954出口で違反0だが最小slackは1、最大window利用率99.9999%。endpoint総和も既存ledgerの望遠和。

Lean counterexamples

high candidateのraw課金は多対一

candidate 285の再利用、既出output 2935、異candidateの同output 265、reuse intervalの5重overlapを認証。strict high blockのoverlap深度は2Mで427。

exact computation

unrestricted Hall は C*=9

20,000,000項まで検証。唯一の最悪区間は [2,6]、demand 13、subtraction mass 4、count 1。

conjectural theorem

tail interval は sharp C*=3

p≥7 のall-job tail intervalで5,000,000項まで成立。候補 TailHall₃ は未証明。

paper lemma

最大加算runの長さ2は不可能

減算後に2回加算すると、3回目の候補は減算前の値そのもの。したがって3回目も必ず加算し、run長は1または3以上。

no-go

H6の21類は局所算術で消えない

mod 4、parity、ledger、legal/forced初出生成のすべてを通る抽象suffixがあり、局所合同類攻略を停止。

countermodel

free history は偽blockerを許す

多数の局所不変量を満たしても、履歴を自由に選ぶとRecamán軌道ではないblockerを生成できる。

causal probe

10億項で最長加算runは6

最初の記録は [5026070,5026075]。同じ値のsaturation source再利用も最大2。ただし両方とも未証明で、単独では全域性に届かない。

logical gap

linear height だけでは矛盾しない

TailHall₃ から期待される liminf aₙ/n≤3 は非自明だが、固定missing targetのpermanent-above tailと両立する。

07 / ANALOGUES

解決された類似問題から何を借りるか

全射性や大域構造まで証明されたgreedy数列の原論文を比較した。最も近いのは「目標が候補になる機会」と「妨害資源」を同じevent上で数える方法である。

permutation proved

EKG sequence

素数ごとのleast-unused multiple frontierを作り、windowへのentry/exitとcontrolling-prime ladderをsieveで数える。

permutation proved

Yellowstone permutation

最小未出値を選ばせる局所状態遷移を作り、その遷移が永遠に消える可能性を素数の再来で排除する。

surjectivity proved

Binary Enots Wolley

target opportunityが十分あれば出現する。P/Q/PQの二側計数で、目標を永久に妨害する仮定を矛盾させる。現在の最優先参照例。

structural analogue

Binary Two-Up

有限種類のatomsと局所倍化algorithmで全履歴を記述する。Recamánではrun長でなくgap provenanceが有限状態に閉じる場合だけ候補。

転用時の決定的な差: これらの列は全未使用整数から最小eligible候補を選べる。Recamánは候補が二点だけで、positive blockerも再利用される。したがって必要なのはglobal least-choiceの模倣ではなく、target levelを飛び越すepisodeをprovenance classへ課金する輸送補題である。

09 / RESEARCH RULES

再開条件と、やらないこと

停止を有効にするには、何が起きたら再開するかも固定する。これで同じ枝を別名で再導入するのを防ぐ。

直接形式化を再開してよい条件

  • eventual-high corridorを直接排除するcanonical不変量
  • post-reset blocker birthを有限化するindependently testable global invariant
  • right-ladder countermodelを破り、target occurrenceを仮定しないglobal constraint
  • gap backlogの増加をpermanent missingと矛盾させる非循環なflux定理

次にやらないこと

  • outcome型・certificate・rank wrapperの追加
  • q / parity / mod 4の追加有限分類
  • fixed horizonのtrace・mex・canonical replay拡張
  • fresh tokenやrecord-gap係数の再包装
  • target出現と同値な仮説の言い換え
  • 既存identityだけから自動的に出る評価
